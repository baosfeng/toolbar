# 03 style · 四个设计体系包 × 两个面板

同一结构（菜单面板 t1 三段 tab / 剪贴板面板 p1 卡片流），只换**视觉语言**——不是换 token 颜色，而是按每个包的设计特征重画。

## raycast（深色首基调）

| 特征 | 在页面里怎么落地 |
|---|---|
| 近黑蓝底 `#07080a` + Surface 100 `#101111` | 页面底色用 `--bg`，面板与卡片用 `--surface`，靠明度差分层 |
| 多层阴影 + 1px inset 高光 | 面板 `inset 0 1px 0 color-mix(fg 7%)` + `0 18px 44px shadow 55%`，卡片选中再加外阴影 |
| 红色只做点状 | `--accent` 只出现在「选中卡右上角 6px 圆点」+ 焦点环，不做大面积填充 |
| 字重 500/600、圆角 12 | 数值 600、标签 400；面板 `--radius-lg`（16）与卡片 `--radius-md`（12） |
| 高密度列表 | 进程行 24px、卡片 168×190 不变 |

## linear（深色首基调）

| 特征 | 在页面里怎么落地 |
|---|---|
| 近黑 `#08090a` + `#191a1b` 表面 | 面板用 `--surface`，页面 `--bg`，边界靠 1px 半透明白 |
| 靛紫 `#5e6ad2` 只给 active/CTA | 选中 tab 用 `color-mix(accent 20%)` 底、柱状图最后一天用 accent、卡片选中描边；其余全灰阶 |
| 510 中间字重 | 数值 / 进程名 / 卡片正文统一 `font-weight:510`（Inter Variable 的可变字重） |
| 高密度但克制 | pane 间距 8、进程行 22、分隔线用 `--border-soft` |
| 圆角 8 | 面板 `--radius-lg`（12）、卡片 `--radius-md`（8） |

## clean（浅色首基调）

| 特征 | 在页面里怎么落地 |
|---|---|
| 纯白 + 大留白 | 页面/面板/卡片全 `--bg` 白；pane padding 20/18、间距 20；卡片 padding 12、间距 12 |
| 极简线条、无阴影 | 面板 `box-shadow:none`、1px `--border`；卡片 1px 边框无阴影 |
| 黑白为主（accent 即 #111） | 选中态用 `--fg` 描边、最后一个柱用 `--fg`；没有彩色强调 |
| 字体 400/600 分工 | 标签 400 + 字距 .02em，选中 tab 600，数值 26px/600/-.03em |
| 结构：顶部下划线 tab | tab 不用胶囊，改成下划线式（`border-bottom: 2px solid`），更接近「安静」的气质 |

> `clean` 的 DESIGN.md 偏空，上面判断基于它的 `tokens.css` 实际取值（纯白底、`--surface #f7f7f7`、`--accent #111111`、4/8/12 圆角、Inter 字体栈）+ 命名语义「clean = 极简留白」。若与预期不符，请指出，我按你的描述调整。

## notion（浅色首基调）

| 特征 | 在页面里怎么落地 |
|---|---|
| 暖白 `#f6f5f4` + near-black `rgba(0,0,0,.95)` | 页面 `--bg` 白、区块 `--surface` 暖白；正文用 `--fg`、次要文字用暖灰 `--muted` |
| 1px `rgba(0,0,0,.1)` 细边框、几乎无阴影 | 面板与卡片 1px `--border`，阴影只留 `0 1px 2px 6%` |
| Notion 蓝只给链接/CTA | `--accent` 只用于选中卡片描边与最后一天柱；tab 用下划线而非蓝色 |
| 文档式排版 | pane 间距 10、行高 1.5、区块标题 600；分隔线 `--border-soft` |
| 圆角 4/8 | 面板 `--radius-md`（8）、卡片 `--radius-sm`（4），比另三款更方正 |

## 一致性底线（8 页都满足）

真实 App 图标 base64 内嵌、线性 SVG 1.5px、无 emoji、无外链；菜单面板三 tab 可切换（点击 + ←/→）、空态保留；剪贴板面板搜索过滤 / 类型过滤 / ↑↓ 选中 / ⌘1–9 徽标 / 收藏星 / 贴屏幕底部展示。
