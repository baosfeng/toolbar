# 03 v · 视觉层三版对照（结构不变：t1 顶部分段 + 三页）

用户否决 08 原型的视觉质量（「排版不合理，ui 不好看」），结构与交互保留，只重做视觉语言。

- **v1 精致原生**：最贴 macOS 系统浮层 —— 半透明材质（`backdrop-filter: blur(30px) saturate(180%)` + 半透明底）、14px 圆角、细分隔线靠灰阶分层；速率 26px 双栏（下行绿 / 上行橙）；进程行 28px 带 **20×20 圆角字母徽标**；近 6 日用**细柱状图**，最新一天（10/16）用强调蓝高亮。**保留**：系统一致性、材质真实感、信息可扫读；**牺牲**：半透明材质在浅色桌面上层次靠假设，实机 vibrancy 需 NSVisualEffectView 复现。
- **v2 数据仪表盘**：速率 26px 占 hero 左栏 + **迷你 sparkline**（近 60s 走势示意），上行降权为右栏 14px；今日流量用**双进度条**（下行 80% / 上行 20% 占比）；进程行带**带宽占比横条**（按最大 1.2 MB/s 归一）；近 6 日柱状图**每根带数值**。**保留**：密度与信息量最高、数据关系一眼可比；**牺牲**：sparkline 是示意数据（接入时要用真实采样）、视觉噪音最多、最容易被读成「监控面板」而非「菜单」。
- **v3 极简留白**：大留白（pane padding 20/16/24）、几乎无线条、分组只靠间距；标题 13–14px、正文 12px；进程只列 **Top 3 + 「查看全部 5 个」**；近 6 日只有紧凑柱形、不标每根数值。**保留**：气质清爽、克制、字号阶梯最干净；**牺牲**：默认屏看不到全部进程与日流量数值，需要一次额外点击才能穷尽。

## 共同约束（三版都满足）

- 4pt 网格：行高 24 / 28 / 32，组间距 12–20，面板内边距 12–16；
- 字号阶梯：hero 26px / 区块标题 10–11px 600 + 字距 .02em / 正文 12px / 辅助 9–11px；
- 数字一律 `font-variant-numeric: tabular-nums` + mono 栈；
- 每屏唯一主角 = 速率（26px），次级信息统一灰阶降权；
- **调试壳移出面板**：demo 标签与状态切换条放在面板下方 24px、11px、muted，带 `demo-only:*` 标记；
- 图标/徽标全部 inline SVG / CSS 徽标，无 emoji、无外链；
- 深色只重绑语义 token，不写第二套结构；tab 交叉淡入 150ms、数值无滚动、`prefers-reduced-motion` 兜底。
