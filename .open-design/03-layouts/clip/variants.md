# 03 clip · 剪贴板历史面板三版结构

现状：`ClipboardPanelController.swift` 的 640×260 浮动面板（贴屏幕底部、`NSVisualEffectView` 材质、非激活）。三版共用 v2 视觉语言（字号阶梯 / 灰阶 / accent / 1.5px 线性 SVG / 圆角材质 / 真实 App 图标）。

- **p1 横向卡片流·精修**：维持 640×260 现状结构（工具条 + 168×190 卡片横向滚动 + 底部提示），只做视觉升级。**保留**：与现有实现一对一映射、卡片展示 4 行摘要足够、横向滚动符合「最近优先」的心智；**牺牲**：一屏只看得到 3.5 张卡，8 条要横滚，键盘扫描效率低于列表。
- **p2 紧凑纵向列表**：640×360，每行 44px（类型图标 / 缩略图 + 单行摘要 + 来源 App + 相对时间 + ⌘1–9 徽标）。**保留**：一屏 6–7 条、↑↓ 扫描最快、⌘1–9 直选在行尾可见；**牺牲**：摘要只能单行截断，长文本要靠 hover/预览，图片卡片缩略图偏小。
- **p3 左列表 + 右预览**：760×340，左 260 列表（同 p2 行式）+ 右 460 预览（完整文本可滚动 / 图片大图 / 元信息）。**保留**：长文本与图片能完整看、可扩展成「加标签 / 编辑」；**牺牲**：面板更宽更高（760×340），贴屏幕底部时占屏比例更大，列表区只剩 260px 宽、摘要截断更狠。

## 共同交互（三版都实现）

搜索框按文案子串实时过滤、类型过滤（全部/文本/图片/收藏）真实切换、↑↓/←→ 选中、Enter 提示「已粘贴」、Esc 提示「已收起」、⌘1–9 徽标（前 9 条）、收藏星可切换、无结果空态。

## 展示方式

三版都把面板贴在页面**底部**（`justify-content:flex-end` + 18px 底距），带中性桌面底色，便于评审看出真实位置观感。

## 待拍板

用户选定一版 → 作为剪贴板面板的定稿结构，落 `08-clipboard.html`；菜单栏面板继续走 08 的验收。

## final（r9 收敛稿）

- 层级：剪贴内容唯一主角（占卡片 ≥66%），元信息全部降到 10px muted。
- **App 图标取舍：保留 12px 图标、删掉 App 名文字，放右下角与时间同行。**
  - 理由一：来源是「这条是谁复制的」的唯一线索，删掉后用户只能靠内容猜；
  - 理由二：真实 App 图标在 12px 仍可辨认（Safari 圆盘 / Terminal 方块 / Notes 黄条），比文字更省空间；
  - 理由三：放到右下角与时间同一行、降到 12px + 75% 不透明度后，视觉权重低于内容，不构成「突出软件名」的问题。
- 粘贴次数 `×N` 直接移除：它是排序而非识别信息，卡片上放不下第三层信息。
- p1/p2/p3 保留不删，等用户验收 final 后统一清理。
