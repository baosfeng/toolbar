→ [监控数据长时间运行后失效](踩坑/运行时/监控数据长时间运行后失效.md) — 额度页整页空白 = 暂停态短路（无对外连接）；今日流量恒 0 = 累计回退后基准失配
→ [像素取色偏移](踩坑/运行时/像素取色偏移.md) — 重绘取色三连坑：色彩空间转换、字节序、行序；马赛克缩小时插值选错会退化成纯黑/纯白
→ [设置窗弱引用即释放](踩坑/运行时/设置窗弱引用即释放.md) — `weak` 捕获局部变量、无强引用持有者时窗口创建即销毁，表现是「show() 无任何反应」
→ [SQLite 绑定传 nil 不复制内容](踩坑/构建/sqlite绑定传nil不复制内容.md) — destructor 传 nil 等于 SQLITE_STATIC，`(value as NSString).utf8String` 释放即悬空；统一走 TRANSIENT
→ [Swift 扩展不能有存储属性](踩坑/构建/Swift扩展不能有存储属性.md) — 按门禁拆文件时，存储属性与 override 方法必须留在主类，跨文件成员需放宽为 internal
→ [nettop 进程流量漏记](踩坑/运行时/nettop-进程流量漏记.md) — 重复传 `-m` 只保留最后一个（实际退化为仅 UDP），TCP 进程全部缺席；用 `-J bytes_in,bytes_out` 固定列数
→ [进程 CPU 百分比时基换算](踩坑/运行时/进程CPU百分比时基换算.md) — `pti_total_user/system` 单位是 mach ticks 不是纳秒，timebase=125/3 时按 ns 换算会小 41.67 倍（3 线程自旋误算 7.2% vs 正确 298.0%）
→ [IOReport 读取崩溃](踩坑/运行时/IOReport读取崩溃.md) — 三处 SIGSEGV 用法（nil callback 建 dict、unsafeBitCast 取通道元素、按 ChannelGetFormat 分派）与唯一稳定写法
→ [打包脚本按名字杀进程连坐](踩坑/构建/打包脚本按名字杀进程连坐.md) — `pgrep -f APP_NAME` 会命中无关进程，多行 PID 传给 `kill` 整条报错被 `|| true` 吞掉，旧实例存活、新版本静默不生效
→ [自签名 App 读钥匙串会卡死](踩坑/运行时/自签名App读钥匙串卡死.md) — 签名身份每次重建都变 → ACL 弹框阻塞主线程；启用钥匙串的前置条件是 designated requirement 不含 cdhash
→ [OSLog 的 public 字段全本机可读](踩坑/运行时/OSLog的public字段全本机可读.md) — 日志写路径 / PIN / 凭据等于广播，进日志前必须过 `LogRedaction`
→ [快照取证需打包成 app](踩坑/构建/快照取证需打包成app.md) — 裸二进制跑 `NM_SNAPSHOT_DIR` 必崩 `bundleProxyForCurrentProcess is nil`，须 `SKIP_INSTALL=1 ./Scripts/build-app.sh debug` 后跑包内可执行文件
→ [@unchecked Sendable 标记需求](踩坑/swift-并发/unchecked-sendable.md) — 类遵循 `Sendable` 却含 `var` 可变存储属性、线程安全靠串行队列保证时编译器无法验证，须标 `@unchecked Sendable`
→ [@MainActor 类适配 nonisolated 协议需要 @preconcurrency](踩坑/swift-并发/preconcurrency-mainactor.md) — `@MainActor` 类适配非 isolated 协议报 `ConformanceIsolation`，在协议名前加 `@preconcurrency` 降级为运行时检查
