# 网络速度监控

## 概述

实时监控 macOS 系统网络接口的上传和下载速度，通过菜单栏显示当前网速。

使用 `getifaddrs()` 系统调用读取所有非回环（non-loopback）网络接口的字节计数器，通过差分法计算每秒的传输速率。

## 核心类

| 名称 | 说明 |
|------|------|
| `NetworkSpeedMonitor` | 网络接口字节计数器读取与速度计算核心类 |
| `ProcessNetworkMonitor` | 基于 `nettop` 的进程级网络流量监控 |
| `MenuBarManager` | 菜单栏显示管理和定时器驱动 |
| `DualLabelView` | 菜单栏自定义视图，使用 SF Symbols 图标显示上下行速度 |
| `DetailPanel` | 详情面板（NSPanel），展示详细网络信息与进程流量 |
| `AppDelegate` | 应用代理，负责应用生命周期管理 |

### NetworkSpeedMonitor

网络监控的核心实现，提供以下功能：

- `poll()` — 定时采集当前网速，计算每秒下载/上传速率
- `downloadSpeed` — 当前下载速度（字节/秒）
- `uploadSpeed` — 当前上传速度（字节/秒）
- `totalRx` — 自启动以来总接收字节数
- `totalTx` — 自启动以来总发送字节数

### MenuBarManager

菜单栏 UI 管理，提供以下功能：

- 创建 `NSStatusItem` 在菜单栏显示网速
- 下拉菜单显示详细速度和总传输量
- 使用 `Timer` 每隔 1 秒触发网速更新
- 使用 `ByteCountFormatter`（十进制）格式化字节显示

## 使用方式

```swift
import AppKit
import Darwin

// 创建监控实例
let monitor = NetworkSpeedMonitor()

// 定时采集（通常由 Timer 驱动，每秒一次）
monitor.poll()

// 读取当前速度
let downSpeed = monitor.downloadSpeed   // 下载速度（字节/秒）
let upSpeed = monitor.uploadSpeed       // 上传速度（字节/秒）
let totalRx = monitor.totalRx           // 总接收字节数
let totalTx = monitor.totalTx           // 总发送字节数
```

## 技术要点

- 使用 `getifaddrs()` 获取网络接口列表
- 过滤 `lo0` 回环接口，只监控物理网络接口
- 通过 `AF_LINK` 地址族获取链路层字节计数器
- 采用溢出安全的无符号整数运算（`&+=`）
