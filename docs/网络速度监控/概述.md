# 网络速度监控

## 概述

菜单栏实时显示网络速度（上行/下行），支持进程级流量查看、每日流量汇总和详情面板。

**网络**：使用 `getifaddrs()` 系统调用读取所有非回环（non-loopback）网络接口的字节计数器，通过差分法计算每秒的传输速率。

**每日流量**：以每日首次启动时的累计流量为基准，追踪今日上传/下载总量，并保存近30天日志。

### BatteryMonitor

```swift
let monitor = BatteryMonitor()
monitor.poll()
let status = monitor.status
// status.percentage → 76
// status.isCharging → false
// status.timeLabel  → "剩余2时15分"
```

### NetworkSpeedMonitor

```swift
let monitor = NetworkSpeedMonitor(totalRx: 0, totalTx: 0)
monitor.poll()
let downSpeed = monitor.downloadSpeed   // 下载速度（字节/秒）
let upSpeed = monitor.uploadSpeed       // 上传速度（字节/秒）
let totalRx = monitor.totalRx           // 总接收字节数
let totalTx = monitor.totalTx           // 总发送字节数
```

### ProcessNetworkMonitor

```swift
let processMonitor = ProcessNetworkMonitor()
processMonitor.poll()
let speeds = processMonitor.processSpeeds  // [ProcessNetUsage]
// 按总流量降序排列，取 Top 10
```

### MenuBarManager

菜单栏 UI 管理，提供以下功能：

- 创建 `NSStatusItem` 在菜单栏显示网速
- 下拉菜单：标题栏（今日流量）、网络信息、活跃进程、电池、流量汇总
- 使用 `Timer` 每隔 1 秒触发更新
- 双击打开详情面板
- 开机自启动管理（`SMAppService`）

## 技术要点

- **网络**：使用 `getifaddrs()` 获取网络接口列表，过滤 `lo0` 回环接口
- **字节计数**：通过 `AF_LINK` 地址族获取链路层字节计数器
- **溢出安全**：采用溢出安全的无符号整数运算（`&+=`）
- **网速计算**：差分法（当前采样值 - 上次采样值）/ 时间间隔
- **流量追踪**：基于 `UserDefaults` 持久化的日基准值，跨日期自动切换
- **菜单栏显示**：使用 `attributedTitle`（NSAttributedString），替代传统的自定义 NSView，显著降低 CPU 占用
- **进程监控**：调用系统 `nettop -x` 命令解析进程级流量数据
- **nettop 回退**：当 shell 命令无返回时使用模拟数据（开发/演示用）

## 每日流量追踪

每日流量统计以**首次启动时的累计流量**为基准点：

1. 应用启动时记录当日基准值（`dayStartRx` / `dayStartTx`）
2. 实时差值 = 当前累计 - 基准值
3. 跨日期时自动将昨日日志存入 `UserDefaults.dailyLogKey`
4. 保留最近 30 天日志
5. 菜单栏标题栏显示"今日 ↓XX ↑XX"
