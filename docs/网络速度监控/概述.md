# 网速 & 电池监控

## 概述

菜单栏实时显示电池状态和网络速度，模仿经典「网速&电池」应用风格。

**电池**：使用 `IOKit.ps`（`IOPSCopyPowerSourcesInfo`）读取电池百分比、充电状态、剩余时间、健康度和循环次数。

**网络**：使用 `getifaddrs()` 系统调用读取所有非回环（non-loopback）网络接口的字节计数器，通过差分法计算每秒的传输速率。

## 核心类

| 名称 | 说明 |
|------|------|
| `NetworkSpeedMonitor` | 网络接口字节计数器读取与速度计算核心类 |
| `BatteryMonitor` | 使用 IOKit 读取电池状态（百分比/充电/健康/循环） |
| `ProcessNetworkMonitor` | 基于 `nettop` 的进程级网络流量监控 |
| `MenuBarManager` | 菜单栏显示管理和定时器驱动 |
| `StatusBarView` | 菜单栏自定义视图，显示电池图标+百分比+网络速度 |
| `DetailPanel` | 详情面板（NSPanel），展示电池详情+网络详情+进程流量 |
| `AppDelegate` | 应用代理，负责应用生命周期管理 |

### BatteryMonitor

```swift
let monitor = BatteryMonitor()
monitor.poll()
let status = monitor.status
// status.percentage → 76
// status.isCharging → false
// status.timeLabel  → "剩余2时15分"
```

### NetworkSpeedMonitor

```swift
let monitor = NetworkSpeedMonitor()
monitor.poll()
let downSpeed = monitor.downloadSpeed   // 下载速度（字节/秒）
let upSpeed = monitor.uploadSpeed       // 上传速度（字节/秒）
let totalRx = monitor.totalRx           // 总接收字节数
let totalTx = monitor.totalTx           // 总发送字节数
```

### MenuBarManager

菜单栏 UI 管理，提供以下功能：

- 创建 `NSStatusItem` 在菜单栏显示电池+网速
- 下拉菜单显示电池详情和网络详情和活跃进程
- 使用 `Timer` 每隔 1 秒触发更新
- 双击打开详情面板

## 技术要点

- 电池使用 `IOKit.ps` 框架，通过 `IOPSCopyPowerSourcesInfo()` 获取电源信息
- 网络使用 `getifaddrs()` 获取网络接口列表，过滤 `lo0` 回环接口
- 通过 `AF_LINK` 地址族获取链路层字节计数器
- 采用溢出安全的无符号整数运算（`&+=`）
