# 离屏快照里投影的三种「看不见」

> **何时阅读：** 给卡片 / 面板加了 `CALayer` 投影，用 `cacheDisplay` 出图核对时「图上没有投影」；
> 或者改了投影参数截图看不出变化，不确定是参数没生效、被裁掉，还是根本没渲染。

## 问题描述

本轮给剪贴板卡片加投影（`shadowRadius` 6 / `shadowOpacity` 0.12 / offset (0,-1)，只在 hover 与选中时出现），
核对走既有离屏快照通道（`MenuPanelSnapshot.render` → `container.cacheDisplay(in:to:)`，
`MenuPanelSnapshot.swift:263`）。同一份「白色圆角小卡 + 投影」，换写法结论完全不同，
而且**用肉眼或「暗像素个数」都判不清**。

## 实测（160×160 画布，64×64 圆角卡，逐像素对比「有阴影 / 无阴影」两张图）

判定口径：两张图亮度差 > 0.01 的像素数，即为投影实际覆盖面积。

| 阴影宿主写法 | 投影差异像素 |
|---|---|
| 视图自身 backing layer（视图 `draw` 画圆角底色） | 3064 |
| 裸 `CAShapeLayer` 子层，`fillColor` 有值 | 3060 |
| 裸 `CAShapeLayer` 子层，`fillColor` 为 nil（只设 `shadowPath`） | **0** |
| 视图 backing layer，但宿主 `masksToBounds = true` | **168**（只剩圆角内侧抗锯齿） |

三条各自独立的失效原因：

1. **阴影按宿主图层自身的可见内容渲染**：`fillColor` 为 nil 的 `CAShapeLayer` 没有任何 alpha，
   即使设了 `shadowPath` 也不会画出投影；但把它改成视图的 backing layer、或有填充色的子层就正常。
2. **`masksToBounds = true` 会把自己的投影裁掉**：投影是画在图层边界之外的，裁切后只剩圆角内侧一点。
   产品的卡片层因此显式 `masksToBounds = false`（`ClipboardCardView.swift:343`），
   只有缩略图层才开裁切（`ClipboardCardView.swift:326`）。
3. **单图阈值会假阴性**：0.95 浅底 + 0.12 不透明度的柔和投影，最暗处亮度可能仍高于任何「暗像素」阈值，
   于是「明明有投影」被数成 0。

## 解决方案

- **判定投影一律用「有阴影 / 无阴影」两张图逐像素做差**，不要用单图亮度阈值，也不要只靠看图。
- 阴影宿主用**视图自己的 backing layer**：视图负责 `draw` 圆角底色，阴影设在同一层的
  `shadowColor / shadowOpacity / shadowRadius / shadowOffset / shadowPath`；
  `shadowPath` 在 `layout()` 里按最终 `bounds` 重设（零尺寸 `bounds` 固化出来的路径不可信）。
- 阴影宿主的 `masksToBounds` 保持 `false`；需要圆角裁切的子视图（缩略图）单独开 `true`。
- 装饰层（底色 / 高亮 / 缩略图）一律不接鼠标（`hitTest` 返回 nil），顺带保证投影层不挡卡片点击。

参考实现：`ClipboardCardBackgroundView`（视图 + backing layer 阴影）、
`ClipboardCardHighlightView`（纯视图绘制状态叠色，不用裸图层）。

## 如何识别

- 快照里「应该有投影的区域」是纯底色 → 先做两图差定位，再谈参数；不要直接调 `shadowOpacity`；
- 投影只在圆角内侧露出一点毛边 → 查宿主 `masksToBounds`；
- 换了 `shadowRadius` / `shadowOffset` 图上毫无变化 → 查阴影宿主是不是没有可见内容的裸图层。

## 边界

本轮只对**离屏 `cacheDisplay` 通道**做了上面的对照实测；真机合成路径的观感仍以实机复核为准，
不要把离屏结论直接当成真机定论（同类教训见 [离屏快照里 NSImage 会上下颠倒](离屏快照里NSImage会上下颠倒.md)）。
