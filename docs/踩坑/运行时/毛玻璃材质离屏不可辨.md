# 毛玻璃材质在离屏快照里不可辨

> **何时阅读：** 给面板 / 浮层加了 `NSVisualEffectView` 材质（`.hudWindow` / `.underWindowBackground` / `.sidebar` 等），
> 用 `cacheDisplay` 出图核对「两级材质」「材质变深 / 变浅」却看不出差别；
> 或者加了内衬之后离屏底色数值大幅变化，怀疑产品被改灰了。

## 问题描述

剪贴板面板要求「`.hudWindow` 底 + `.underWindowBackground` 内衬」两级材质。
按既有离屏通道（`MenuPanelSnapshot.render` → `cacheDisplay(in:to:)`）出图后：

- 改动前 / 改动后两张 `panel-clipboard-light.png` 肉眼几乎看不出差别；
- 但同一位置像素值从 `255` 变成 `228`（浅色）、`30` 变成 `58`（深色）——数值变了，观感没变。

## 原因

`NSVisualEffectView` 的模糊材质由**窗口服务器合成**（`blendingMode = .behindWindow` 时取窗口背后的桌面内容做模糊），
离屏 `cacheDisplay` 只走视图自己的绘制，材质层退化为「近似底色 + 无模糊」。
因此：

- 图上看不出「材质 vs 材质」的差别是**通道限制**，不是内衬没挂上；
- 内衬的近似底色会把整块面板的离屏像素拉偏（浅色 255 → 228），**它不代表真机观感**。

## 解决方案

材质类改动一律用三种判据组合，不以单张离屏图定论：

1. **结构自证（主）**：探针直接编译真实产品源文件，打印运行时结构并断言 ——
   层级顺序（谁在谁上面）、`material` / `blendingMode` / `state`、`cornerRadius`、内缩量、
   `autoresizingMask`、`hitTest == nil`（装饰层不吃鼠标）、不同画布尺寸下的 frame。
2. **像素旁证（辅）**：只用来证「材质边界存在」——本轮直边逐像素是「外层 1pt 环 → 内衬」，
   色调差 27（浅）/ 28（深），圆角亚像素拟合 11.1pt（配置 12pt）。
3. **真机确认**：毛玻璃观感、真实色调差必须在真机上复核；离屏数值不作为调参依据。

## 如何识别

- 两张图肉眼无差、像素值却明显变了 → 先怀疑是 `NSVisualEffectView` 的离屏近似，别急着改 `material`；
- 材质层的子视图被内衬盖住（例如父视图自绘的分隔线）→ 内衬是所有控件的底层，
  自绘内容要么提到内衬之上单独成层，要么改成独立的装饰视图；
- 装饰层吃掉点击 → 在装饰视图上 `hitTest` 返回 `nil`，别指望容器去转发。

## 边界

本轮只验证了 `.hudWindow` + `.underWindowBackground` 这一组两层的结构；
其它材质组合（`.sidebar` / `.menu` / `withinWindow` 混合）的离屏近似色未逐组实测。
