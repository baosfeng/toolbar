# 设置窗创建后不显示

> **何时阅读：** 新建的窗口调用 `show()` 却什么都没出现，没有报错也没有崩溃。

## 问题描述

设置窗创建后调 `show()`，界面上什么都没发生。日志里也看不到异常，只有「窗口已打开」这类正常记录。

定位到组合根里这一行：

```swift
let snipSettings = SnipSettingsWindow(...)
snipController.onOpenSettings = { [weak snipSettings] in snipSettings?.show() }
```

`snipSettings` 是局部常量，被 `weak` 捕获后没有任何强引用持有它 —— 函数返回即释放，闭包里的 `snipSettings` 永远是 nil。

## 触发条件

- 用 `weak` 捕获局部变量
- 该对象没有同时被存入组合根属性、集合或其它长期持有者

## 解决方案

先存到组合根属性，再让闭包弱引用 `self`：

```swift
snipSettings = SnipSettingsWindow(...)
snipController.onOpenSettings = { [weak self] in self?.snipSettings.show() }
```

## 如何识别

- 加一行日志打印闭包里的可选值是否为 nil
- 界面类问题用截图取证：先 `show()`，等 600ms 后截一张全屏 PNG 看有没有窗口
