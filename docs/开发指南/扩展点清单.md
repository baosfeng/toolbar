## 7. 测试套件（新增一个 `*Tests.swift`）

| 必改 | 位置 | 判据 |
|---|---|---|
| 在域登记函数里加一行 | `Sources/TestRunner/TestSuites+<域>.swift`（Core / Clipboard / Snip / Billing / Token / Pane / System / Transfer） | **main.swift 不用改**（只剩域调度，40 行且不再增长）；选不准域就选最接近的，域只影响执行顺序分组 |

机制：

- 断言失败**累计**，套件跑完由 `main.swift` 末尾 `TestAssertions.finish()` 统一 `exit(1)`，一次能看到全部 ❌（见 `Sources/TestRunner/TestAssertions.swift`）。
  `guard ... else { exit(1) }` 这类「后续断言没意义」的前置条件失败仍然即停，语义不变。
- 忘了登记不会编译报错，也不会有人发现——由 `TestSuiteRegistrationTests` 扫描目录判定「定义了却没有任何调用 = 孤儿」并判红。

必补测试：自己（孤儿判定已覆盖）；退出码语义 0 = 全绿。

必更新文档：无（本表即规范）。

## 附：三条通用判据

1. **计数断言会红是设计如此**：`PanelTabCatalogTests` / `SettingsThemeTests` / `NotificationTests` 里的硬编码数字是「冻结契约」，加一类东西时改数字是本次改动的一部分，不是噪音。
2. **偏好键一旦写出就不可改名**：分页 id、设置分类 id、provider kindID、通知事件 rawValue 都会进 `UserDefaults`；改名 = 清空用户配置，只能加迁移（参照 `PanelTabCatalog.legacyRawValueToStableID` 与 `BillingInstance` 的「默认实例沿用旧键」）。
3. **懒装配漏了最隐蔽**：页签在、页也在，但切过去空白（`docs/踩坑/运行时/菜单面板内存常驻.md`）。
