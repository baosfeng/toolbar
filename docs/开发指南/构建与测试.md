# 构建与测试

> ⚠️ **何时阅读：** 当你需要构建项目、运行测试或进行代码提交时，必须先阅读本文档。

## 环境要求

- macOS 14 (Sonoma) 或更高版本
- Xcode 16+ 或 Swift 6.3+ 命令行工具
- Apple Silicon (ARM64)

## 项目架构

```
NetworkMonitor/
├── Sources/
│   ├── NetworkMonitorCore/     ← 库目标 — 可测试的业务逻辑
│   │   ├── Core.swift          ← 工具函数 (formatSpeedShort, sparkline, parseNettopLine…)
│   │   ├── Models.swift        ← 数据模型 (EventType, TodayStats, AppUsage)
│   │   ├── DatabaseManager.swift    ← SQLite 数据库管理器
│   │   ├── StatsProvider.swift      ← 统计查询器
│   │   ├── ReportGenerator.swift    ← 报告生成器
│   │   ├── SystemSampler.swift      ← 系统采样器
│   │   └── ReasonixHookModels.swift ← Hook 事件数据模型
│   │
│   ├── NetworkMonitor/         ← 可执行目标 — UI 代码（AppKit 依赖）
│   │   ├── main.swift
│   │   ├── AppDelegate.swift
│   │   ├── MenuBarManager.swift
│   │   ├── NetworkMonitor.swift
│   │   ├── StatusBarView.swift
│   │   ├── DetailPanel.swift
│   │   ├── EventMonitor.swift
│   │   ├── KeyPressMonitor.swift
│   │   ├── WindowTitleMonitor.swift
│   │   └── ReasonixHookMonitor.swift
│   │
│   └── TestRunner/             ← 可执行目标 — 测试入口
│       └── main.swift          ← 全部测试用例
│
├── dist/                       ← 构建产物
│   └── NetworkMonitor.app
├── Package.swift
└── Scripts/
    └── build-app.sh
```

**设计原则：**
- `NetworkMonitorCore` 不依赖 AppKit，可在 TestRunner 中直接测试
- 所有业务逻辑（数据库、统计、报告、采样）在 `NetworkMonitorCore` 中
- UI 代码（菜单栏、面板、AppKit 通知监听）保持在 `NetworkMonitor` 中
- 测试使用 in-memory SQLite，无需真实数据库文件

## 构建 + 打包 + 部署（推荐方式）

一键编译、打包为 .app、部署到 `/Applications` 并自动启动：

```bash
cd NetworkMonitor
./Scripts/build-app.sh
```

这个脚本自动完成：
1. `swift build --target NetworkMonitor --disable-sandbox`
2. 创建 `dist/NetworkMonitor.app` 包结构
3. 复制可执行文件 + 图标
4. 写入 Info.plist（含 LSUIElement 隐藏 Dock 图标）
5. **杀掉正在运行的旧版本**（如有）
6. **复制到 `/Applications/NetworkMonitor.app`**
7. **自动启动新版本应用**

## 仅编译（不打包）

```bash
cd NetworkMonitor
swift build --disable-sandbox
```

## 运行

使用 `build-app.sh` 打包部署后，应用会自动启动。也可以通过以下方式手动运行：

```bash
# 方式一：从 /Applications 打开（推荐）
open /Applications/NetworkMonitor.app

# 方式二：从构建产物目录打开
open dist/NetworkMonitor.app

# 方式三：终端直接运行
swift run
```

## 产物目录

构建后的可分发包统一放在 `dist/` 目录下，脚本会自动将其部署到 `/Applications/`：

```
NetworkMonitor/
├── dist/
│   └── NetworkMonitor.app      # 构建产物（双击可运行）
└── /Applications/
    └── NetworkMonitor.app      # 自动部署的应用（推荐从此处启动）
```

`dist/` 目录下的内容已添加到 `.gitignore`，不进入版本控制。

## 测试

```bash
cd NetworkMonitor

# 运行全部测试
swift run --disable-sandbox TestRunner
```

测试覆盖以下模块：
- `NetworkMonitorCore` 工具函数 — formatSpeedShort、parseNettopLine、sparkline、formatBytesFull
- `DatabaseManager` — in-memory SQLite 初始化、事件写入（app_open/close、system_sample、key_press）、批量刷新、查询
- `StatsProvider` — 有数据/无数据场景下的统计查询（今日活跃时间、击键数、CPU/内存、应用排行）
- `ReportGenerator` — 每日报告文件生成与内容验证

### 添加新测试

1. 编辑 `Sources/TestRunner/main.swift`
2. 使用 `assertEqual` / `assertNotNil` 断言
3. 测试失败时 `exit(1)`，成功时打印 ✅
4. 运行 `swift run --disable-sandbox TestRunner` 验证

### 测试数据

测试使用 in-memory SQLite 数据库（`DatabaseManager.initializeInMemory()`），无需真实数据库文件，每次测试独立实例。

## 提交前流程

每次代码修改完成后必须按以下顺序执行：

```
① 编译 → ② 测试 → ③ 打包部署 → ④ 提交
```

即：
```bash
# 1. 编译
swift build --disable-sandbox

# 2. 测试
swift run --disable-sandbox TestRunner

# 3. 打包部署（自动杀掉旧进程、复制到 /Applications、启动新版本）
./Scripts/build-app.sh

# 4. 提交
git add ...
git commit -m "..."
```
