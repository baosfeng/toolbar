# 构建与测试

> ⚠️ **何时阅读：** 当你需要构建项目、运行测试或进行代码提交时，必须先阅读本文档。

## 环境要求

- macOS 14 (Sonoma) 或更高版本
- Xcode 16+ 或 Swift 6.3+ 命令行工具
- Apple Silicon (ARM64)

## 构建 + 打包（推荐方式）

一键编译并打包为 .app：

```bash
cd NetworkMonitor
./Scripts/build-app.sh
```

这个脚本自动完成：
1. `swift build --target NetworkMonitor --disable-sandbox`
2. 创建 `dist/NetworkMonitor.app` 包结构
3. 复制可执行文件 + 图标
4. 写入 Info.plist（含 LSUIElement 隐藏 Dock 图标）

## 仅编译（不打包）

```bash
cd NetworkMonitor
swift build --disable-sandbox
```

## 运行

```bash
# 方式一：双击 .app（推荐）
open dist/NetworkMonitor.app

# 方式二：终端直接运行
swift run
```

## 产物目录

构建后的可分发包统一放在 `dist/` 目录下：

```
dist/
└── NetworkMonitor.app      # 双击运行的 app bundle
```

`dist/` 目录下的内容已添加到 `.gitignore`，不进入版本控制。

## 测试

```bash
cd NetworkMonitor

# SQLite 核心功能测试（9 项）
swift Scripts/test-macmonitor.swift
```

## 提交前流程

每次代码修改完成后必须按以下顺序执行：

```
① 编译 → ② 打包为 .app → ③ 提交
```

即：
```bash
# 1. 编译
swift build --disable-sandbox

# 2. 打包
./Scripts/build-app.sh

# 3. 提交
git add ...
git commit -m "..."
```

## 测试执行要求

> **提交前必须运行测试，修复所有失败的测试用例，确保全部通过。**
