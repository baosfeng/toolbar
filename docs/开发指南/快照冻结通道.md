# 快照冻结通道（NM_SNAPSHOT_FREEZE）

> **何时阅读：** 要给 Token / 额度 / 网络 / 系统页做**逐像素回归**、或要一张「每次跑都一模一样」的验收图时先看这里。

## 为什么需要它

同一份快照函数既出验收图、又做回归比对。这几页里有实时数值与时钟，**同一份代码连跑两次差异约 10%**，
逐像素比对永远收敛不了——此前只能靠「平坦区分析 + 台账几何字段比对」绕过去，那是绕，不是解。

冻结通道把「会变的东西」收敛成固定值，于是同一冻结时刻下每次产出的 PNG 逐字节相同。

## 怎么用

```bash
# 打包（快照要走包内可执行文件，裸二进制会在 UserNotifications 上崩）
cd NetworkMonitor && SKIP_INSTALL=1 ./Scripts/build-app.sh
APP=dist/一览.app/Contents/MacOS/一览

# 冻结：epoch 秒（推荐，跨越多次运行也能对上）
NM_SNAPSHOT_FREEZE=1794729600 NM_SNAPSHOT_DIR=/tmp/snap-a "$APP"

# 冻结：对齐到当前整分钟（同一次多张图之间要对齐时用）
NM_SNAPSHOT_FREEZE=now NM_SNAPSHOT_DIR=/tmp/snap-b "$APP"

# 不设 NM_SNAPSHOT_FREEZE = 真实数据 + 真实时钟（与改造前完全一致）
NM_SNAPSHOT_DIR=/tmp/snap-live "$APP"
```

回比对：

```bash
shasum -a 256 /tmp/snap-a/menu-token-light.png /tmp/snap-b/menu-token-light.png
```

## 冻结了什么

| 维度 | 冻结后 | 位置 |
|------|--------|------|
| 时钟 | `SnapshotClock.now` 恒为固定时刻 | `NetworkMonitorCore/Infrastructure/SnapshotClock.swift` |
| Token 页数据 | 固定 fixture（会话数 / 日序列 / 24 小时桶 / 项目榜 / 模型榜全部写死） | `Debug/SnapshotFreeze.swift` |
| Token 页日期键 | 按冻结时刻推导，同一时刻恒定 | `TokenDerive.dailyBuckets` / `previousDailyBuckets` |
| 额度页时间基准 | 冻结时刻（所有 `resetsAt` / `lastUpdated` 由它派生） | `MenuPanel/BillingPanePreview.swift` |
| 近 6 日柱状图标签 | 冻结时刻倒推 | `Debug/SnapshotFixtures.swift` |

**未冻结时的语义不变**：`SnapshotClock.now` 就是 `Date()`，release 构建里 `frozen` 恒为 nil。

## 实测结果

同一冻结时刻连跑两次（147 个产物）：

```
same=147 diff=0
```

Token / 额度两张关键页：

```
SAME  menu-token-light.png    fb859362714c72090b3260f0154146bbd76afd3da39c45190c8017ab5d0aa6e5
SAME  menu-credits-light.png  225c7c3a4502c32d5a6ed4cef5c79f9b0d55fa8decf0dfc10f5fbc7d3e7103e0
SAME  menu-clipboard-light.png    6b0c95d5f17a4d91f39e9be8d3ff42d9e76a31786f50fd972f00109c7b0ca7cb
SAME  panel-clipboard-light.png   8ef49055c01871482177fcb5c865d3efa7dcb01ae282a9dde577216b27a732d1
```

此前有 6 个产物不一致，已在本轮收口：

- 剪贴板两页（`menu-clipboard-*` / `panel-clipboard-*`）：`ClipboardRelativeTime.string(from:)`
  默认取真实时钟，「N 分钟前」跨分钟就变。三处调用点（面板行 / 卡片 meta / 悬停浮层）改为
  注入 `SnapshotClock.now`，fixture 的 `createdAt` 基准同样走冻结时钟。
  实测差异 38 / 40 个像素、bbox 正好落在时间文本处，改完后归零。
- `settings-appearance-states.txt` / `settings-toolbar-states.txt`：快照流程里同一页会被装配两次
  （首屏 + 滚动到底取证），原实现一律追加，于是同一个 `[snapshot]` 行写了两遍。
  改为按 tag 幂等写入（`SnapshotEvidenceLine`），后写覆盖先写。

不冻结时对照跑两次，Token / 额度页**确实不同**（`DIFF`），证明冻结开关真的在起作用，而不是本来就不变。

## 加新页面时的口径

1. 页面里所有取时间的地方改读 `SnapshotClock.now`（不要直接 `Date()`）；
2. 数据来自真实数据源的，加一条「冻结时走固定 fixture」分支，判据统一用 `SnapshotFreeze.isFrozen`；
3. 加完后跑一次 `NM_SNAPSHOT_FREEZE=<固定值>` 两次，确认该页 PNG 的 sha256 相同；
4. 若该页确实无法冻结（依赖真实外部状态），在本文「实测结果」里写明原因，不要假装它通过了。
