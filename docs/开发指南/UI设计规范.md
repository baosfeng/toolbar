# UI 设计规范

> ⚠️ **何时阅读：** 在开发任何新功能或修改现有 UI 之前，**必须先阅读本文档**。本文档规定了「先设计、后开发」的工作流程和 UI 设计标准。

## 核心理念：先设计，后开发

### 原则

1. **设计先行** — 在写任何 UI 代码之前，先用设计稿（或 mockup）确定布局、颜色、字体、图标与交互
2. **系统原生优先** — 优先使用系统原生的 SF Symbols 图标集和系统颜色（`NSColor`），保持 macOS 平台一致性
3. **一致的设计语言** — 所有界面共享同一套色彩、间距、字体层级
4. **少即是多** — 信息展示要克制，避免信息过载；用视觉层级引导用户注意力

### 工作流程

```
需求分析 → 设计草图 → 设计确认 → 编码实现 → UI 走查
```

| 阶段 | 输出 | 说明 |
|------|------|------|
| 需求分析 | 功能列表 + 用户故事 | 明确要做什么、给谁用 |
| 设计草图 | Figma / SwiftUI Preview / 手绘稿 | 确定布局、交互流程 |
| 设计确认 | 在团队或自审中确认设计合理 | 确保一致性和可用性 |
| 编码实现 | 符合本规范的 Swift 代码 | 使用系统组件 + SF Symbols |
| UI 走查 | 截图对比 + 像素级检查 | 检查间距、颜色、对齐 |

## 设计系统

### 🎨 色彩系统

| 用途 | 颜色 | 色值（深色模式） | 色值（浅色模式） |
|------|------|------------------|------------------|
| 主色（品牌） | `systemBlue` | — | — |
| 下载速度 | `systemGreen` | `#30D158` | `#34C759` |
| 上传速度 | `systemOrange` | `#FF9F0A` | `#FF9500` |
| 警告/错误 | `systemRed` | `#FF453A` | `#FF3B30` |
| 次要文本 | `secondaryLabelColor` | — | — |
| 背景（面板） | `windowBackgroundColor` | — | — |
| 分割线 | `separatorColor` | — | — |

> 始终使用 `NSColor` 的系统命名颜色，确保自动适配深色/浅色模式。

### 🔤 字体层级

| 层级 | 字体 | 大小 | 字重 | 用途 |
|------|------|------|------|------|
| 大数字 | `monospacedDigitSystemFont` | 28 | `.bold` | 详情面板速度数值 |
| 正文 | `systemFont` | 13 | `.regular` | 标签、描述文本 |
| 辅助 | `systemFont` | 11 | `.regular` | 进程列表、小字信息 |
| 菜单栏 | `monospacedDigitSystemFont` | 10 | `.regular` | 菜单栏速度数字 |

### 📐 间距系统

使用 4 为基准的间距系统：

| Token | 值 | 用途 |
|-------|-----|------|
| `spacing(1)` | 4pt | 紧凑间距 |
| `spacing(2)` | 8pt | 默认间距 |
| `spacing(3)` | 12pt | 分组间距 |
| `spacing(4)` | 16pt | 面板边距 |
| `spacing(5)` | 20pt | 大间距 |
| `spacing(6)` | 24pt | 段落间距 |

### 🎯 图标系统（SF Symbols）

**所有图标必须使用 SF Symbols**（macOS 内置），不要使用 emoji 或自定义图片。

| 用途 | SF Symbol 名称 | 示例 |
|------|---------------|------|
| 下载 | `arrow.down.circle.fill` | ↓● |
| 上传 | `arrow.up.circle.fill` | ↑● |
| Wi-Fi | `wifi` | 📶 |
| IP 地址 | `network` | 🌐 |
| 进程/应用 | `app.connected.to.app.below.fill` | ◻ |
| 详情面板 | `info.circle.fill` | ℹ️ |
| 复制 | `doc.on.doc` | 📄 |
| 导出 | `square.and.arrow.up` | ⬆ |
| 退出 | `power` | ⏻ |
| 设置 | `gear` | ⚙️ |
| 趋势/图表 | `chart.line.uptrend.xyaxis` | 📈 |
| 总计 | `arrow.down.arrow.up` | ↕ |
| 启动项 | `clock.arrow.circlepath` | 🔄 |
| 空状态 | `tray.full` | 📥 |

> SF Symbols 可通过 `NSImage(systemSymbolName:accessibilityDescription:)` 加载。

## 菜单栏设计规范

作为菜单栏 App，设计上应遵循以下原则：

1. **简洁克制** — 菜单栏空间有限，只展示最重要的信息（下载/上传速度）
2. **一目了然** — 用户只需扫一眼就能知道当前网络状态
3. **交互直观** — 单击展开菜单，双击打开详情面板
4. **信息层级清晰** — 速度 > Wi-Fi/IP 状态 > 进程详情 > 操作

### 菜单栏视图布局

```
┌──────────────────────┐
│     ▼ 1.2 MB/s      │  ← 绿色下载速度
│     ▲ 340 KB/s      │  ← 橙色上传速度
└──────────────────────┘
```

## 检查清单

开发 UI 前/后，请对照以下清单检查：

- [ ] 是否先做了设计草图/原型？
- [ ] 是否使用了 SF Symbols 而非 emoji？
- [ ] 颜色是否使用了 `NSColor` 系统颜色？
- [ ] 字体是否使用了系统字体（`systemFont` / `monospacedDigitSystemFont`）？
- [ ] 间距是否符合 4pt 基准体系？
- [ ] 是否适配了深色/浅色模式？
- [ ] 信息层级是否合理？
- [ ] 交互是否直观（单击/双击/右键）？
