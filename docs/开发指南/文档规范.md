# 文档规范

> **何时阅读：** 创建、修改或删除项目文档前。

## 核心规则

- 所有文档**必须使用中文**（代码标识符、命令、报错信息保留原文）
- 文件与目录名**必须使用中文**，统一放在 `docs/` 下
- 每篇文档只聚焦一个主题，通过相对路径互相引用
- **每篇文档至少被索引或其他文档引用一次**，禁止孤立文档
- 计划/任务类临时文档完成后立即删除，不得提交
- **规范类内容不写入 docs/**：编码/UI/异常/版本号/代码查询规范一律写入 `.reasonix/skills/` 下的项目 skill，禁止另建独立规范文档

## 结构约定

- 文档层级不超过 2 层目录
- 新增文档必须同步更新 `docs/索引.md`
- 功能模块目录名保持固定映射，无重大重构不得更改基线结构

## AGENTS.md 约定

AGENTS.md 是每个会话自动注入的入口，必须精简（项目标识、简介、文档导航、开发规范链接），与 `docs/索引.md` 内容保持一致。

## 代码示例规范

- Swift 代码使用 PascalCase 类名、camelCase 方法/变量名
- 使用项目版本支持的最新语法（Swift 6.3）
- 注释使用中文

## 踩坑文档维护

- 踩坑按功能域组织在 `docs/踩坑/` 下，每个踩坑条目一个文件（文件名中文描述）
- 去重：相同 `file:line` 或相同标题视为同一问题

## ✅ 自查

- [ ] 文件名中文、层级 ≤2 层
- [ ] 已在 `docs/索引.md` 添加引用（非孤立）
- [ ] 计划/任务类临时文档已删除
- [ ] 规范类内容未写入 docs/（应写入 skill）
