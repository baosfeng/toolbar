# macMonitor 数据存储设计

> **状态：** 规划中，尚未编码实现
> **方案：** SQLite 本地数据库

## 数据库表结构

### events 表（原始事件记录）

```sql
CREATE TABLE events (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    event_type TEXT NOT NULL,       -- 'app_open', 'app_close', 'app_switch',
                                   -- 'screen_sleep', 'screen_wake',
                                   -- 'system_sleep', 'system_wake',
                                   -- 'power_ac', 'power_battery',
                                   -- 'window_title'
    app_name TEXT,                  -- 关联的应用名（如果适用）
    app_bundle_id TEXT,             -- 应用的 Bundle ID
    window_title TEXT,              -- 窗口标题（如果适用）
    timestamp REAL NOT NULL,        -- Unix 时间戳（秒，含小数）
    extra_data TEXT                 -- JSON 扩展数据
);

CREATE INDEX idx_events_timestamp ON events(timestamp);
CREATE INDEX idx_events_type ON events(event_type);
```

### stats_hourly 表（小时聚合统计）

```sql
CREATE TABLE stats_hourly (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    date TEXT NOT NULL,             -- '2026-06-30'
    hour INTEGER NOT NULL,          -- 0-23
    app_name TEXT NOT NULL,         -- 应用名
    bundle_id TEXT,
    total_seconds REAL DEFAULT 0,   -- 前台使用秒数
    keypress_count INTEGER DEFAULT 0,
    cpu_avg REAL DEFAULT 0,        -- 平均CPU%
    memory_avg REAL DEFAULT 0,     -- 平均内存MB
    network_rx INTEGER DEFAULT 0,  -- 接收字节
    network_tx INTEGER DEFAULT 0,  -- 发送字节
    UNIQUE(date, hour, bundle_id)
);
```

### stats_daily 表（每日汇总）

```sql
CREATE TABLE stats_daily (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    date TEXT NOT NULL UNIQUE,       -- '2026-06-30'
    total_active_seconds REAL DEFAULT 0,  -- 活跃总秒数
    total_idle_seconds REAL DEFAULT 0,    -- 空闲总秒数
    total_keypress INTEGER DEFAULT 0,
    screen_on_seconds REAL DEFAULT 0,
    screen_off_seconds REAL DEFAULT 0,
    power_on_battery_seconds REAL DEFAULT 0,
    power_on_ac_seconds REAL DEFAULT 0
);
```

## 数据目录

```
~/Library/Application Support/macMonitor/
├── monitor.db          ← 主数据库
└── reports/            ← 可选：导出的报告文件
    ├── 2026-06-30.md
    └── 2026-W27.md
```

## 数据持久化原则

- **重装 App 不影响数据**：删除 `.app` 文件不会删除 `~/Library/Application Support/macMonitor/` 目录
- **迁移电脑时**：复制整个 `macMonitor/` 文件夹到新电脑即可恢复所有历史数据
- **数据安全**：磁盘满了也不会丢数据（写入失败有异常保护）
- **无网络依赖**：所有数据仅存本地，不上传任何云端
