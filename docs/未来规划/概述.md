# macMonitor 本机监控 — 未来规划概述

> **版本：** v1.0（规划中）
> **源自设计文档：** 2026-06-30
> **状态：** 已归档规划，尚未编码实现
> **关联：** 作为现有 NetworkMonitor 的功能扩展与全面升级

## 产品定位

macMonitor 是一个运行在 macOS 菜单栏的轻量级本机监控软件，默默在后台记录用户在电脑上的各种活动——打开了什么软件、用了多久、息屏亮屏时间、击键数量等——所有数据存在本地，通过菜单栏图标点开查看每日/每周统计报告。

### 核心设计目标

- **极低内存占用**（目标 < 20MB）
- **极低功耗**（平均 CPU < 0.2%）
- **全本地运行**，不上传任何数据
- **单 `.app` 文件**，双击即用，零配置

## 功能清单

### 应用监控
| 功能 | 描述 | 实现方式 | 功耗 |
|------|------|----------|------|
| 应用打开/关闭 | 记录每个应用何时启动、何时退出 | NSWorkspace 通知监听 | 被动通知，≈0% |
| 应用前台切换 | 记录用户切换到哪个应用 | NSWorkspace 通知监听 | 被动通知，≈0% |
| 各软件使用时长 | 从前台切换到后台自动计时 | 事件驱动计算 | ≈0% |
| 窗口标题 | 切换到某个应用时获取其窗口标题 | Accessibility API | 切换时单次获取 |
| 今日最活跃排行 | 按使用时长给应用排序 | 从数据库查询统计 | 仅在点开菜单时计算 |

### 系统监控
| 功能 | 描述 | 实现方式 | 功耗 |
|------|------|----------|------|
| 息屏/亮屏 | 记录屏幕关闭和打开时间 | NSWorkspace 通知监听 | 被动通知，≈0% |
| 系统休眠/唤醒 | 记录系统休眠和唤醒 | NSWorkspace 通知监听 | 被动通知，≈0% |
| 电源状态 | 记录插电/使用电池切换 | IOKit / NSWorkspace 电源通知 | 被动通知，≈0% |
| CPU/内存占用 | 每60秒采样各进程CPU和内存 | `proc_pidinfo` / `host_statistics` / `task_info` | 每60秒采样100ms |
| 网络流量 | 每60秒采样各进程收发字节数 | `nstat` / `getifaddrs` + `proc_pidfdinfo` | 随CPU采样一起 |

### 输入监控
| 功能 | 描述 | 实现方式 | 功耗 |
|------|------|----------|------|
| 击键计数 | 统计总共按了多少下键盘 | CGEventTap 监听，仅计数不记录内容 | 极低（事件过滤） |
| 活跃/空闲判断 | 多长时间没有操作判定为空闲 | 通过按键/鼠标事件时间戳推断 | ≈0%（复用事件） |

### 报告与展示
| 功能 | 描述 | 实现方式 |
|------|------|----------|
| 菜单栏图标 | 系统顶部菜单栏显示图标 | NSStatusBar.system.statusItem |
| 下拉菜单 | 点击图标弹出今日概览 | NSMenu 自定义视图 |
| 今日统计 | 应用使用排行、活跃时间、击键数等 | 下拉菜单中直接展示 |
| 每日报告 | 每天自动生成昨日汇总报告 | Markdown 格式存入 reports/ 目录 |
| 每周报告 | 每周一自动生成上周汇总报告 | Markdown 格式存入 reports/ 目录 |
