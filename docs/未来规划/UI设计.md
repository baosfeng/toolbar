# macMonitor UI 设计

> **状态：** 规划中，尚未编码实现
> **风格：** macOS 原生设计语言

## 设计风格

- **风格**：macOS 原生设计语言，毛玻璃效果（NSVisualEffectView）
- **配色**：跟随系统深色/浅色模式自动切换
- **字体**：系统默认 SF Pro
- **圆角**：所有卡片 8px 圆角
- **图标**：SF Symbols 系统图标

## 菜单栏图标

```
┌───────────────────────────────────────────────────┐
│  🌙  03:24  🔋 92%  |    文件  编辑  视图  ...  │  ← 系统菜单栏
│              📊 macMonitor                        │  ← 我们的图标
└───────────────────────────────────────────────────┘
```

图标状态变化：
- ⬜ **白色图标**（默认）：正常监控中
- 🌙 **变暗**：屏幕已息屏
- 🔴 **红点**：监控异常/无权限

## 交互细节

| 元素 | 交互 |
|------|------|
| 活跃软件排行 | 鼠标悬停高亮，点击可查看该软件的详细时段 |
| 指标卡片 | 鼠标悬停显示更精确的数字 |
| 报告按钮 | 点击用默认文本编辑器打开 Markdown 报告 |
| 开机自启 | 点击切换，自动安装/卸载 LaunchAgent |
| 右键菜单栏图标 | 快速开关监控、查看版本号 |
