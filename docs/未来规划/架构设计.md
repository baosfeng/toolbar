# macMonitor 架构设计

> **状态：** 规划中，尚未编码实现

## 整体架构

```
┌─────────────────────────────────────────────┐
│               菜单栏 UI 层                     │
│    NSStatusBar → NSMenu → 自定义视图          │
└──────────────────────┬──────────────────────┘
                       │ 查询
┌──────────────────────▼──────────────────────┐
│              数据存储层 (SQLite)               │
│    ~/Library/Application Support/macMonitor/ │
│    monitor.db (events + stats 两张表)        │
└──────────────────────┬──────────────────────┘
                       │ 写入
┌──────────────────────▼──────────────────────┐
│             事件/采样引擎                      │
├──────────────────┬──────────────────────────┤
│  被动监听 (Event) │  定时采样 (Sampler)        │
│  - NSWorkspace   │  - CPU/Memory (60s)       │
│  - CGEventTap    │  - Network (60s)          │
│  - IOKit         │                           │
└──────────────────┴──────────────────────────┘
```

## 模块划分

| 模块 | 职责 | 依赖 |
|------|------|------|
| AppDelegate | 应用入口、菜单栏初始化、权限检查 | AppKit |
| EventMonitor | 监听所有系统通知（应用、屏幕、电源） | Foundation, AppKit |
| KeyPressMonitor | 监听击键事件（仅计数） | CoreGraphics |
| WindowTitleMonitor | 获取前台窗口标题 | Accessibility API |
| SystemSampler | 定时采集CPU/内存/网络数据 | Foundation |
| DatabaseManager | SQLite 数据存取 | SQLite3 (系统自带) |
| StatsCalculator | 计算统计数据（排行、汇总） | — |
| MenuViewController | 管理菜单栏下拉视图 | AppKit |
| ReportGenerator | 生成每日/每周报告 | — |

## 数据流

```
事件发生 (应用切换/息屏/按键等)
    │
    ▼
EventMonitor / KeyPressMonitor
    │  记录到内存缓冲区
    ▼
DatabaseManager.batchWrite()  ← 每30秒或累计10条
    │
    ▼
SQLite (monitor.db)
    │
    ▼  (用户点击菜单栏)
MenuViewController.query()
    │
    ▼
显示今日统计
```
