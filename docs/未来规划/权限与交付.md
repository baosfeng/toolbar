# macMonitor 权限、交付与非功能性需求

> **状态：** 规划中，尚未编码实现

## 权限需求

首次运行时需要用户授权：

| 权限 | 用途 | 设置路径 |
|------|------|----------|
| **辅助功能** (Accessibility) | 获取当前窗口标题 | 系统设置 → 隐私与安全性 → 辅助功能 |
| **输入监控** (Input Monitoring) | 统计击键次数（不记录内容） | 系统设置 → 隐私与安全性 → 输入监控 |

> **隐私说明**：所有数据仅保存在本地，不会上传网络。击键仅计数不记录内容。

## 非功能性需求

### 性能指标

| 指标 | 目标 |
|------|------|
| 内存占用 | 运行态 < 20MB |
| CPU 占用 | 平均 < 0.2%，峰值 < 2% |
| 磁盘写入 | < 10KB/天（数据库） |
| 启动速度 | < 1秒 |
| 应用体积 | < 5MB (.app) |

### 功耗优化策略

1. 所有系统监控采用 **被动监听**（通知机制），避免轮询
2. CPU/内存/网络采样使用 **60秒间隔**，且一次性采集
3. 数据库采用 **批量写入**（每30秒或满10条），避免频繁IO
4. 菜单栏 UI 只在用户点击时才刷新
5. 使用 `DispatchQueue.global(qos: .background)` 处理非UI任务

### 可靠性

- 数据库写入失败不影响主程序（catch 异常）
- 程序崩溃重启后能继续记录（以事件时间戳为准）
- 支持 macOS 开机自启（通过 LaunchAgent plist）

## 交付物

最终交付一个 `.app` 文件夹：

```
macMonitor.app/
├── Contents/
│   ├── MacOS/
│   │   └── macMonitor        ← 编译好的可执行文件
│   ├── Resources/
│   │   └── icon.icns         ← 应用图标
│   └── Info.plist            ← 应用配置
```

用户只需：
1. 将 `macMonitor.app` 拖入「应用程序」文件夹
2. 双击运行
3. 按提示授权权限
4. 顶部菜单栏出现图标 → 开始自动监控
