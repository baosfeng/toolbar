# MacMonitor 使用指南

> 👋 欢迎！本指南面向**不需要懂代码**的普通 Mac 用户。

## 📦 这是什么？

MacMonitor 是一个**菜单栏小工具**，默默在后台记录你电脑上的活动：

- 📱 打开了什么软件、用了多久
- 🌐 实时网络速度、每日流量汇总
- 🔋 电池健康、循环次数
- ⌨️ 今天按了多少次键盘（仅计数，不记录内容）
- 💡 屏幕亮了多久、息屏多久
- 💻 CPU、内存使用情况
- 📊 每天自动生成统计报告

> 🔒 **隐私安全**：所有数据仅存在你电脑本地，**不上传任何网络**。

---

## 🚀 三步上手

### 第一步：找到应用

构建完成后，应用在以下位置：

```
/Applications/NetworkMonitor.app
```

或者在项目目录：
```
项目文件夹/NetworkMonitor/dist/NetworkMonitor.app
```

### 第二步：运行应用

1. **双击** `NetworkMonitor.app`
2. 如果是第一次运行，系统会提示"无法验证开发者"
   - ✅ 这是正常的，因为我们没有购买 Apple 开发者证书
   - 请**右键点击** → **打开** → 选择"打开"
3. 菜单栏顶部会出现 **↑XX/s  ↓XX/s** 网速显示 → 开始监控！

> 💡 如果以后想每次开机自动启动，可以从菜单中开启"开机自启"

### 第三步：查看数据

点击菜单栏的网速区域，弹出下拉菜单：

| 区域 | 内容 |
|------|------|
| 📊 标题栏 | 今日流量汇总（下载/上传总量） |
| 🌐 网络信息 | IP 地址、Wi-Fi 名称 |
| 📱 活跃进程 | 按流量排名的进程列表 |
| 🔋 电池 | 百分比、剩余时间、循环次数、健康度 |
| 🖥️ 本机监控 | 活跃时间、击键数、CPU/内存、亮屏/息屏 |
| 📈 流量汇总 | 今日 + 近7日流量总和 |
| 📅 报告按钮 | 生成每日/每周报告 |

**双击菜单栏区域**可打开详情面板，查看更全面的信息。

## 🔐 权限说明

某些功能需要授权才能工作：

| 功能 | 需要权限 | 如何授权 |
|------|---------|---------|
| 窗口标题 | 辅助功能 | 系统设置 → 隐私 → 辅助功能 → 勾选 NetworkMonitor |
| 击键计数 | 输入监控 | 系统设置 → 隐私 → 输入监控 → 勾选 NetworkMonitor |

> 🔒 **再次承诺**：击键只统计"按了多少下"，**不会记录你输入了什么内容**。

## 📁 数据存在哪里？

所有数据存在你的电脑上：

```
~/Library/Application Support/macMonitor/
├── monitor.db      ← 数据库（所有活动记录）
└── reports/        ← 报告（Markdown 格式）
```

**删除应用不会丢失数据**，重装后历史记录依然在。

如果想完全删除所有数据，手动删除 `~/Library/Application Support/macMonitor/` 文件夹即可。

## ❓ 常见问题

**Q: 为什么第一次打不开？**
A: 因为应用没有 Apple 签名，请右键 → 打开。

**Q: 怎么退出？**
A: 点击菜单栏退出按钮，或快捷键 `⌘Q`。

**Q: 会消耗很多电量吗？**
A: 不会。所有监控都是被动监听，CPU 占用 < 0.2%，菜单栏使用 attributedTitle 比自定义视图更省电。

**Q: 数据会上传到云端吗？**
A: **绝对不会**。所有数据仅存本地，没有任何网络上传功能。

**Q: 什么是"每日流量"？**
A: 从你今日首次启动应用开始统计的上传/下载总量，第二天自动归零重新统计。

## 💻 给开发者/高级用户的快速命令

```bash
# 构建 + 打包为 .app 并部署到 /Applications
cd NetworkMonitor
./Scripts/build-app.sh

# 仅编译（不打包）
swift build --disable-sandbox

# 运行测试
swift run --target TestRunner
```
