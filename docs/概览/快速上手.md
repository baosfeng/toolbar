# NetworkMonitor 使用指南

> 👋 欢迎！本指南面向**不需要懂代码**的普通 Mac 用户。

## 📦 这是什么？

NetworkMonitor 是一个**菜单栏小工具**：

- 🌐 实时网络速度、每日流量汇总
- 🧠 AI 助手 Token 用量与花费统计（通过 Reasonix Hook 接收）
- 🤖 AI 工具/模型/项目分析、轮次完成通知
- 🖥️ 活跃进程流量 Top 10

> 🔒 **隐私安全**：所有数据仅存在你电脑本地，**不上传任何网络**。

---

## 🚀 三步上手

### 第一步：找到应用

构建完成后，应用在以下位置：

```
/Applications/NetworkMonitor.app
```

或者在项目目录：
```
项目文件夹/NetworkMonitor/dist/NetworkMonitor.app
```

### 第二步：运行应用

1. **双击** `NetworkMonitor.app`
2. 如果是第一次运行，系统会提示"无法验证开发者"
   - ✅ 这是正常的，因为我们没有购买 Apple 开发者证书
   - 请**右键点击** → **打开** → 选择"打开"
3. 菜单栏顶部会出现 **↑XX/s  ↓XX/s** 网速显示 → 开始监控！

> 💡 如果希望每次开机自动启动，可从菜单中开启"开机自启动"

### 第三步：查看数据

点击菜单栏的网速区域，弹出下拉菜单：

| 区域 | 内容 |
|------|------|
| 📊 标题栏 | 今日流量汇总（下载/上传总量） |
| 🌐 网络信息 | IP 地址 |
| 🖥️ 活跃进程 | 按流量排名的进程列表 |
| 📈 流量汇总 | 今日 + 近7日流量明细 |
| 🧠 Token 用量 | 今日 Token 总数、花费（CNY）、24 小时柱状图 |
| 📅 历史用量 | 近 7 日 Token 柱状图 |
| 🤖 AI 分析 | 实时工具动态、工具统计、模型排行、项目排行、会话概览 |

AI 轮次完成/失败时，系统会弹出通知，点击可跳转到对应会话文件。

## 📁 数据存在哪里？

所有数据存在你的电脑上：

```
~/Library/Application Support/macMonitor/
└── monitor.db      ← SQLite 数据库（Token 用量、会话、工具调用）
```

**删除应用不会丢失数据**，重装后历史记录依然在。

如果想完全删除所有数据，手动删除 `~/Library/Application Support/macMonitor/` 文件夹即可。

## ❓ 常见问题

**Q: 为什么第一次打不开？**
A: 因为应用没有 Apple 签名，请右键 → 打开。

**Q: 怎么退出？**
A: 点击菜单栏"退出"按钮，或快捷键 `⌘Q`。

**Q: 会消耗很多电量吗？**
A: 不会。进程监控在后台采样（3 秒一次），统计查询每 15 秒一次且走索引，菜单栏使用 attributedTitle 比自定义视图更省电。

**Q: 数据会上传到云端吗？**
A: **绝对不会**。所有数据仅存本地，没有任何网络上传功能。

**Q: 菜单里显示的"花费"是什么单位？**
A: 人民币（CNY）。AI 花费按汇率（默认 1 USD ≈ 7.2 CNY）换算后存储与显示。

## 💻 给开发者/高级用户的快速命令

```bash
# 构建 + 打包为 .app 并部署到 /Applications
cd NetworkMonitor
./Scripts/build-app.sh

# 仅编译（不打包）
swift build --disable-sandbox

# 运行测试
swift run --disable-sandbox TestRunner
```
