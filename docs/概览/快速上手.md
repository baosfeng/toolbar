# 快速上手

## 环境要求

- macOS 14 (Sonoma) 或更高版本
- Apple Silicon (ARM64)
- Xcode 16+ 或 Swift 6.3+ 命令行工具

## 构建

```bash
# 使用 Swift PM 构建
cd NetworkMonitor
swift build -c release

# 构建产物位于
# .build/release/NetworkMonitor
```

## 运行

### 直接运行

```bash
swift run
```

### 打包为 DMG

构建后，`dist/NetworkMonitor.dmg` 已包含可安装的应用包。

### 安装

1. 打开 `NetworkMonitor.dmg`
2. 将 `NetworkMonitor.app` 拖入 `Applications` 文件夹
3. 首次启动时右键点击 → **打开**（因 ad-hoc 签名需要）

## 使用

- 应用启动后将在菜单栏显示 `▼0 ▲0`
- `▼` 后跟下载速度，`▲` 后跟上载速度
- 点击菜单栏图标可查看详细网速和总传输量
- 快捷键 `⌘Q` 退出应用
