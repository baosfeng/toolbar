# NetworkMonitor — macOS 菜单栏监控

## 一句话介绍

你的 Mac 菜单栏监控助手 —— 实时显示**网络速度与每日流量**，统计 **AI 助手 Token 用量与花费**，所有数据只存在你电脑上。

## 功能一览

| 功能 | 说明 |
|------|------|
| 🌐 **网速监控** | 菜单栏实时显示下载/上传速度，支持进程级流量查看（Top 10） |
| 📊 **每日流量** | 菜单栏标题显示今日流量，二级菜单汇总近7日流量 |
| 🧠 **Token 监控** | 今日 Token 总数与花费（CNY），24 小时柱状图，近7日历史图表 |
| 🤖 **AI 分析** | 实时工具动态、工具统计（成功率/耗时）、模型排行、项目排行、会话概览 |
| 🔔 **轮次通知** | AI 轮次完成/失败时系统通知，点击跳转会话文件 |
| 📡 **Hook 事件接收** | 通过 UDS 接收 Reasonix AI 助手事件，写入本地 SQLite |

## 菜单结构

```
菜单栏:  ↑1.2 MB/s  ↓340 KB/s      ← 实时网速

下拉菜单:
┌─────────────────────────────────┐
│ 今日  ↓12.5GB  ↑3.2GB          │ ← 标题栏（今日流量汇总）
├─────────────────────────────────┤
│ 🌐 IP: 192.168.1.100            │
│ ▶ 活跃进程                      │ ← 二级菜单：进程级流量 Top 10
│ ▶ 流量汇总                      │ ← 二级菜单：今日 + 近7日明细
│ Token: 12.3万 | 花费: ¥8.88    │ ← Token 一级概览
│ 📊 [24小时柱状图]               │
│ ▶ 历史用量                      │ ← 二级菜单：近7日柱状图
│ ▶ AI 分析                       │ ← 二级菜单：实时动态/工具/模型/项目/会话
│ ○ 开机自启动                    │
│ 退出                    ⌘Q      │
└─────────────────────────────────┘
```

## 隐私承诺

- 🔒 **完全本地**：所有数据只存在你电脑上，**不上传任何网络**
- 金额仅统计 Token 用量与花费，不记录对话内容
- 数据存储在 `~/Library/Application Support/macMonitor/`

## 技术信息

| 项目 | 内容 |
|------|------|
| 开发语言 | Swift 6.3 |
| 最低系统 | macOS 14 (Sonoma) |
| 芯片支持 | Apple Silicon (M1/M2/M3/M4) |
| 交付格式 | .app（双击即用，不生成 .dmg） |
| 数据库 | SQLite3（本地存储，WAL 模式） |
| 第三方依赖 | DGCharts（Token 图表），其余纯 Apple 系统框架 |
