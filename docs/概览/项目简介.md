# NetworkMonitor — macOS 菜单栏监控

## 一句话介绍

你的 Mac 菜单栏全能助手 —— 实时显示**网络速度 + 电池状态**，追踪**每日流量**，同时默默记录你每天用了哪些软件、按了多少次键盘，所有数据只存在你电脑上。

## 功能一览

| 功能 | 说明 |
|------|------|
| 🌐 **网速监控** | 菜单栏实时显示下载/上传速度，支持进程级流量查看 |
| 📊 **每日流量** | 菜单栏标题显示今日流量，二级菜单汇总近7日流量 |
| 🔋 **电池信息** | 显示电量百分比、剩余时间、充电状态、循环次数、电池健康 |
| 📱 **应用追踪** | 自动记录你打开了哪些软件、用了多久，生成今日活跃排行 |
| ⌨️ **击键统计** | 统计今天按了多少次键盘（**仅计数，不记录内容**） |
| 💡 **屏幕监控** | 记录亮屏/息屏时间 |
| 💻 **系统资源** | 实时显示 CPU、内存占用 |
| 📊 **统计报告** | 一键生成每日/每周 Markdown 活动报告 |

## 菜单结构

```
菜单栏:  ↑340 KB/s  ↓1.2 MB/s     ← 上行(橙) 下行(绿) 实时网速

下拉菜单:
┌─────────────────────────────────┐
│ 今日  ↓12.5GB  ↑3.2GB          │ ← 标题栏（今日流量汇总）
├─────────────────────────────────┤
│ 🌐 IP: 192.168.1.100            │
│ 📶 Wi-Fi: MyNetwork             │
├─────────────────────────────────┤
│ 活跃进程 ▶                      │ ← 二级菜单：进程级流量 Top 10
│ 电池 ▶                          │ ← 二级菜单：百分比/时间/电源/循环
│ 本机监控 ▶                      │ ← 二级菜单：活跃/击键/CPU/内存
│ 流量汇总 ▶                      │ ← 二级菜单：今日 + 近7日总和
├─────────────────────────────────┤
│ ○ 打开详情面板           ⌘D     │
│ ○ 复制信息               ⌘C     │
│ ○ 导出日志…              ⌘E     │
│ ○ 开机自启动                    │
├─────────────────────────────────┤
│ 退出                    ⌘Q      │
└─────────────────────────────────┘
```

## 隐私承诺

- 🔒 **完全本地**：所有数据只存在你电脑上，**不上传任何网络**
- 击键仅计数，不记录按键内容
- 数据存储在 `~/Library/Application Support/macMonitor/`
