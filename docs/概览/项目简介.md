# 项目简介

## NetworkMonitor

**版本:** 1.0.0

一个轻量级的 macOS 菜单栏应用，实时显示网络上传/下载速度。

### 项目特点

- 📊 **实时网速监控** — 在菜单栏实时显示下载和上传速度
- 🚫 **Dock 隐藏** — 以菜单栏辅助工具方式运行，不占用 Dock
- 💾 **极小体积** — 应用包仅 124K，DMG 仅 28K
- 🔋 **低内存占用** — 纯原生 Swift + AppKit 实现，无 WebKit/Electron
- 🏗️ **ARM64 原生** — Apple Silicon 原生编译

### 技术栈

| 项目 | 内容 |
|------|------|
| 语言 | Swift 6.3 |
| 构建工具 | Swift Package Manager (Swift 6.3) |
| UI 框架 | AppKit |
| 最低系统版本 | macOS 14 (Sonoma) |
| 架构 | ARM64 |

### 功能模块

| 模块 | 说明 |
|------|------|
| 网络速度监控 | 使用 `getifaddrs` 读取网络接口字节计数器，计算实时上传/下载速度 |
