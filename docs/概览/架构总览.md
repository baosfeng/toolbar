# 架构总览

NetworkMonitor 是一个模块化的 macOS 菜单栏应用，采用经典 AppKit 事件驱动架构，展示网速、每日流量汇总和 AI 助手 Token 用量统计。

## 系统分层

```
┌─────────────────────────────────────────────┐
│             应用入口 (main.swift)            │
│        NSApplication + AppDelegate          │
├─────────────────────────────────────────────┤
│      服务协调器 (AppCoordinator)             │
│    依赖注入 + 生命周期管理                    │
├─────────────────────────────────────────────┤
│          菜单栏管理 (MenuBarManager)         │
│     NSStatusItem + NSMenu + Timer           │
│     分层刷新：1s 网速 / 5s 流量 / 15s 统计    │
├─────────────────────────────────────────────┤
│    菜单栏视图 (StatusBarView)                │
│    ▲上行速度(橙)  ▼下行速度(绿)              │
├─────────────────────────────────────────────┤
│        网络监控 (NetworkSpeedMonitor)        │
│   getifaddrs → if_data byte counters        │
├─────────────────────────────────────────────┤
│       进程监控 (ProcessNetworkMonitor)       │
│   nettop 子进程 → 后台队列采样（3s 节流）     │
├─────────────────────────────────────────────┤
│       每日流量追踪 (TrafficTracker)          │
│       UserDefaults 持久化 → 今日/近7日汇总    │
├─────────────────────────────────────────────┤
│    Reasonix Hook 事件监听                    │
│    (ReasonixHookMonitor)                    │
│    UDS Datagram → 事件解析 → 侧车补全 → 落库  │
│    轮次完成/失败 → 系统通知                  │
├─────────────────────────────────────────────┤
│    数据层 (NetworkMonitorCore)               │
│  DatabaseManager(SQLite)                    │
│  TokenUsageProvider(统计查询)                │
│  ReasonixHookModels(模型/解析/缓存)          │
└─────────────────────────────────────────────┘
```

## 目标划分

| SwiftPM 目标 | 类型 | 职责 |
|-------------|------|------|
| `NetworkMonitorCore` | 库 | 领域协议、数据库、Token 统计、模型解析、格式化（无 AppKit 依赖） |
| `NetworkMonitor` | 可执行 | UI、菜单栏、Hook 监听器、网络监控实现 |
| `TestRunner` | 可执行 | 手写断言测试（本机无 Xcode SDK，XCTest 不可用） |

## 展示层 — MenuBarManager

- 管理 `NSStatusItem`（菜单栏图标），创建下拉菜单
- **分层刷新策略**（避免主线程承担重活）：
  - 每秒：网速（getifaddrs 轻量调用）、历史记录
  - 每 5 秒：今日流量标题、IP、进程列表、开机自启状态
  - 每 15 秒：Token 统计 / AI 分析（SQLite 查询）
  - 菜单打开时（`NSMenuDelegate.menuWillOpen`）强制全部刷新
- 菜单结构：网络标题、IP、活跃进程、流量汇总、Token 一级概览 + 24 小时图表、历史用量图表、AI 分析（5 个子菜单）、开机自启动、退出
- 使用 `attributedTitle` 替代自定义 NSView（降低 CPU 占用）

### 刷新节流实现

```swift
// 中频更新（5 秒）：今日流量/IP/进程列表/开机自启
private static let midInterval: TimeInterval = 5.0
// 低频更新（15 秒）：Token 统计 / AI 分析 — 均为 SQLite 查询
private static let statsInterval: TimeInterval = 15.0
```

## 业务层 — NetworkSpeedMonitor

- 使用 `getifaddrs()` 读取所有非回环接口的字节计数器
- 差分法计算每秒下载/上传速度，累加总收发字节
- 过滤 `lo0` 回环接口，溢出安全运算（`&+=`）

## 业务层 — ProcessNetworkMonitor

- 调用系统 `nettop -P -m tcp -m udp -l 1 -x -n` 获取进程级流量
- **后台队列采样**：nettop 子进程（约 1 秒）在 `workQueue` 执行，不阻塞主线程
- 3 秒节流，结果回主线程更新 `processSpeeds`
- 解析见 `parseNettopLine`（Core.swift），按总流量排序取 Top 10

## 每日流量追踪 — TrafficTracker

- 以每日首次启动时的累计流量为基准（`dayStartRx/dayStartTx`）
- 跨日期自动切换并保存近 30 天日志（`dailyLogKey`）
- 通过 `KeyValueStorage` 协议访问 UserDefaults，可注入测试

## Reasonix Hook 事件监听

- UDS Datagram 接收 Reasonix AI 助手事件（`/tmp/reasonix-hook.sock`）
- 事件处理在私有 `eventQueue`（background QoS）上执行
- 侧车数据补全（`SessionSidecarCache`：TTL 1 小时、LRU、最多 100 会话）
- 金额统一转换：USD → CNY（`CurrencyConfig`，汇率可覆盖）
- 每 30 秒健康检查，socket 文件丢失自动重建
- 详细说明 → [Token监控/概述](../Token监控/概述.md)

## 数据层 — DatabaseManager

- SQLite3，存储于 `~/Library/Application Support/macMonitor/monitor.db`
- 全部 sqlite3 调用通过串行队列串行化
- `PRAGMA mmap_size=0`（规避 Apple 平台 purgeable 缓存死锁）+ WAL 模式
- **Schema 迁移**：`PRAGMA user_version` 版本化（v1：cost 统一为 CNY）
- **数据保留**：每日自动清理（明细 90 天 / 会话 180 天）
- **索引策略**：`date(列, 时区偏移)` 表达式索引，保证按日统计查询走索引；
  时区偏移来自 `SqliteTimeZone.offsetModifier`（本地时区，索引与查询共用）

## 统计查询 — TokenUsageProvider

- 今日汇总（按模型分组）、每小时明细（补全 24 小时）、近 7 日历史（补全连续天）
- AI 分析：工具调用排行（近 30 天）、最近工具调用、模型排行、项目排行、会话概览
- 日期过滤均带时间范围限制，避免全表扫描

## 关键设计

- **分层清晰**：Core 无 AppKit 依赖，协议定义在 `Domain/Protocols/`，UI 在 `NetworkMonitor` 目标
- **主线程轻载**：nettop 后台采样、统计查询降频、热路径避免重复创建 DateFormatter
- **Timer+RunLoop**：`.common` mode 的 Timer，菜单打开时仍能更新
- **字节格式化**：十进制（1000 进制）匹配网络行业惯例
- **SF Symbols**：图标使用系统内置符号，视觉与 macOS 一致
- **UDS 事件驱动**：hook 事件后台队列处理，不阻塞主线程
- **本地时区聚合**：统计 SQL 与表达式索引统一使用本地时区偏移
- **金额统一 CNY**：写库前转换，历史数据自动迁移
