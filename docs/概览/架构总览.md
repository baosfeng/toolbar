# 架构总览

NetworkMonitor 是一个单模块的 macOS 菜单栏应用，采用经典 AppKit 事件驱动架构，模仿「网速&电池」应用风格，同时展示电池状态和网络速度。

## 系统分层

```
┌─────────────────────────────────────────────┐
│             应用入口 (main.swift)            │
│        NSApplication + AppDelegate          │
├─────────────────────────────────────────────┤
│          菜单栏管理 (MenuBarManager)         │
│     NSStatusItem + NSMenu + Timer           │
├─────────────────────────────────────────────┤
│    菜单栏视图 (StatusBarView)                │
│    🔋电池 + ▼下载/▲上传                      │
├─────────────────────────────────────────────┤
│    详情面板 (DetailPanel / NSPanel)          │
│    电池卡片 + 网速 + 网络信息 + 进程列表      │
├─────────────────────────────────────────────┤
│       电池监控 (BatteryMonitor)              │
│       IOKit.ps → 百分比/充电/健康/循环        │
├─────────────────────────────────────────────┤
│       进程监控 (ProcessNetworkMonitor)       │
│       nettop → 进程级流量                    │
├─────────────────────────────────────────────┤
│        网络监控 (NetworkSpeedMonitor)        │
│   getifaddrs → if_data byte counters        │
└─────────────────────────────────────────────┘
```

### 展示层 — MenuBarManager
- 管理 `NSStatusItem`（菜单栏图标）
- 创建下拉菜单（`NSMenu`），显示详细信息
- 通过 `Timer` 定期（1 秒）触发网速更新
- 使用 `ByteCountFormatter` 格式化字节数显示

### 展示层 — StatusBarView
- 菜单栏自定义视图，显示电池状态和网络速度
- 第一行：电池 SF Symbols 图标 + 百分比 + 剩余时间
- 第二行：下载速度（绿色）+ 上传速度（橙色）
- 电池图标根据电量动态切换（`battery.100.bolt` / `battery.75` / `battery.50` / `battery.25`）

### 展示层 — DetailPanel
- 浮动详情面板（`NSPanel`）
- 四个视觉分区：
  1. **电池卡片** — 大号电池图标 + 32pt 百分比 + 状态/健康/循环信息
  2. **网速区域** — 下载/上传大号数字速度
  3. **网络信息** — IP/WiFi/总计（带 SF Symbols 图标）
  4. **活跃进程** — 进程流量列表
- 双击菜单栏区域打开

### 电池监控层 — BatteryMonitor
- 使用 `IOKit.ps` 框架，通过 `IOPSCopyPowerSourcesInfo()` 获取电源信息
- 读取 `Current Capacity`、`Max Capacity`、`Is Charging`、`Is Charged`、`Time to Empty`、`Time to Full Charge`、`BatteryHealth`、`DesignCycleCount`
- 提供 `BatteryStatus` 结构体和 `timeLabel` 文本

### 进程监控层 — ProcessNetworkMonitor
- 调用系统 `nettop` 命令获取进程级流量
- 解析 `nettop -x` 输出，计算每个进程的上下行速率
- 按总流量排序，取 Top 10 显示

### 业务层 — NetworkSpeedMonitor
- 使用 `getifaddrs()` 系统调用读取所有非回环网络接口的字节计数器
- 计算每秒的下载和上传速度（差分法）
- 累加总接收/总发送字节数
- 过滤 `lo0` 回环接口

### 入口层 — AppDelegate + main.swift
- 设置 `activationPolicy(.accessory)` 以隐藏 Dock 图标
- 在 `applicationDidFinishLaunching` 时初始化 `MenuBarManager`
- 使用 `@MainActor` 确保所有 UI 操作在主线程执行

## 关键设计

- **纯原生实现：** 无第三方依赖，仅使用 Apple 系统库（AppKit, Foundation, Darwin）
- **单线程模型：** 所有操作在 `@MainActor` 上执行，避免并发复杂性
- **Timer+RunLoop：** 使用 `.common` mode 的 Timer，确保菜单打开时仍能更新
- **字节格式化：** 采用十进制（1000 进制）计数以匹配网络行业惯例
- **SF Symbols：** 所有图标使用系统内置 SF Symbols，确保与 macOS 视觉风格一致
