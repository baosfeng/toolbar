# 架构总览

NetworkMonitor 是一个模块化的 macOS 菜单栏应用，采用经典 AppKit 事件驱动架构，同时展示网速、电池、本机监控信息和每日流量汇总。

## 系统分层

```
┌─────────────────────────────────────────────┐
│             应用入口 (main.swift)            │
│        NSApplication + AppDelegate          │
├─────────────────────────────────────────────┤
│          菜单栏管理 (MenuBarManager)         │
│     NSStatusItem + NSMenu + Timer           │
│    流量汇总二级菜单 + macMonitor二级菜单      │
├─────────────────────────────────────────────┤
│    菜单栏视图 (StatusBarView)                │
│    ▲上行速度(橙)  ▼下行速度(绿)              │
├─────────────────────────────────────────────┤
│    详情面板 (DetailPanel / NSPanel)          │
```

### 展示层 — MenuBarManager
- 管理 `NSStatusItem`（菜单栏图标）
- 创建下拉菜单（`NSMenu`），包含：
  - **标题栏**：显示"今日 ↓流量 ↑流量"
  - **网络信息**：IP、Wi-Fi 状态
  - **活跃进程**（二级菜单）：进程级流量 Top 10
  - **电池**（二级菜单）：百分比、剩余时间、电源、循环/健康
  - **本机监控**（二级菜单）：活跃时间、击键数、CPU/内存、亮屏/息屏
  - **流量汇总**（二级菜单）：今日流量、近7日总和
  - **操作项**：打开详情面板、复制信息、导出日志、开机自启
- 通过 `Timer` 定期（1 秒）触发网速更新
- 使用 `ByteCountFormatter` 格式化字节数显示

### 展示层 — StatusBarView
- 菜单栏属性字符串视图，仅显示网络上行/下行速度
- 格式：`↑340 KB/s  ↓1.2 MB/s`
- 上行橙色，下行绿色
- 使用 `attributedTitle` 替代自定义 NSView（降低 CPU 占用）

### 展示层 — DetailPanel
- 浮动详情面板（`NSPanel`），macOS 15 现代毛玻璃风格
- 五个视觉分区：
  1. **网速区域** — 下载/上传大号数字速度（28pt bold）
  2. **网络信息** — IP/WiFi + 今日流量 + 近7日逐日明细
  3. **电池卡片** — 电池图标 + 32pt 百分比 + 状态/健康/循环信息
  4. **活跃进程** — 进程流量列表
- 双击菜单栏区域打开

### 电池监控层 — BatteryMonitor
- 使用 `IOKit.ps` 框架，通过 `IOPSCopyPowerSourcesInfo()` 获取电源信息
- 读取 `Current Capacity`、`Max Capacity`、`Is Charging`、`Is Charged`、`Time to Empty`、`Time to Full Charge`、`BatteryHealth`、`DesignCycleCount`
- 提供 `BatteryStatus` 结构体和 `timeLabel` 文本
- 定义在 `NetworkMonitorCore/Core.swift` 中

### 进程监控层 — ProcessNetworkMonitor
- 调用系统 `nettop` 命令获取进程级流量
- 解析 `nettop -x` 输出，计算每个进程的上下行速率
- 按总流量排序，取 Top 10 显示

### 业务层 — NetworkSpeedMonitor
- 使用 `getifaddrs()` 系统调用读取所有非回环网络接口的字节计数器
- 计算每秒的下载和上传速度（差分法）
- 累加总接收/总发送字节数
- 过滤 `lo0` 回环接口

### 每日流量追踪模块
- 内置在 `MenuBarManager` 中，通过 `UserDefaults` 持久化
- `dayStartRx/dayStartTx`：以每日首次启动时的累计流量为基准
- `dailyLogKey`：保存近30天的每日日志
- 菜单栏标题栏显示"今日 ↓XX ↑XX"
- 流量汇总二级菜单显示今日和近7日总计

### macMonitor 本机监控子系统

#### 事件监听 (EventMonitor)
- 监听 `NSWorkspace` 通知：应用启动/关闭/切换、屏幕睡眠/唤醒、系统睡眠/唤醒
- 记录事件时间、事件类型到 SQLite 数据库
- 纯被动监听，几乎不消耗 CPU

#### 击键监听 (KeyPressMonitor)
- 使用 `NSEvent.addGlobalMonitorForEvents(matching: .keyDown)` 监听全局键盘事件
- **仅计数，不记录按键内容**
- 每60秒批量写入数据库一次（`writeKeyPressBatch`）
- 需要输入监控权限（`AXIsProcessTrusted()` 检查）

#### 系统采样 (SystemSampler)
- 每60秒采样一次：CPU tick、网络接口字节、内存信息
- 使用 `DispatchSourceTimer` 在后台队列执行
- 采样结果写入数据库

#### 窗口标题 (WindowTitleMonitor)
- 使用 Accessibility API（`AXUIElementCreateApplication`）获取活跃窗口标题
- 在应用切换时单次调用，几乎不消耗资源

#### 数据层
- **DatabaseManager**：SQLite 数据库管理，数据存储在 `~/Library/Application Support/macMonitor/monitor.db`
  - 事件缓冲区批量写入（每10条或每分钟刷入）
  - 自动建表、事务支持
- **StatsProvider**：查询今日统计数据（活跃时间、击键数、亮屏/息屏时间、应用排行、CPU/内存）
- **ReportGenerator**：生成每日/每周 Markdown 格式统计报告
  - 报告存放在 `~/Library/Application Support/macMonitor/reports/`

### 入口层 — AppDelegate + main.swift
- 设置 `activationPolicy(.accessory)` 以隐藏 Dock 图标
- 在 `applicationDidFinishLaunching` 时初始化 `MenuBarManager`
- 退出时刷新数据库缓冲区（`flushBeforeQuit`）
- 使用 `@MainActor` 确保所有 UI 操作在主线程执行

## 关键设计

- **纯原生实现：** 无第三方依赖，仅使用 Apple 系统库（AppKit, Foundation, Darwin, IOKit, ServiceManagement, CoreWLAN, SQLite3）
- **单线程模型：** 所有 UI 操作在 `@MainActor` 上执行，避免并发复杂性
- **Timer+RunLoop：** 使用 `.common` mode 的 Timer，确保菜单打开时仍能更新
- **字节格式化：** 采用十进制（1000 进制）计数以匹配网络行业惯例
- **SF Symbols：** 所有图标使用系统内置 SF Symbols，确保与 macOS 视觉风格一致
- **批量写入：** 数据库采用事件缓冲区批量写入，减少 IO 次数
- **attributedTitle：** 菜单栏使用 `NSAttributedString` 替代自定义 `NSView`，降低 CPU 占用
