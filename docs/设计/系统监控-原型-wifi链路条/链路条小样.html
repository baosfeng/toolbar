取舍说明
决策理由
链路条保留「Wi-Fi」4 字标签面板可能同时存在以太网 / 热点，纯数字 −65 dBm 会被读成「网络信号」；4 字上限内。
信道与频段合并为 ch36 5G 一段拆成「ch36」「5G」两段要多 9pt 间距 + 3pt 间隙，240pt 可用宽吃不下；合并后仍是数值 + 单位。
档位只用 7pt 圆点，不写「一般 / 偏弱」文字档位与 dBm 数值语义重复，且要占 18–22pt；项目既有状态带（电池 / 压力）也是圆点表达档位。
断开时整条保留、全部「—」整条隐藏会让「今日流量」与「活跃进程」之间突然跳动 20pt+10pt 间距；保留占位让版面稳定，且明确表达「Wi-Fi 这一项不可得」而不是「没有 Wi-Fi 这件事」。
