- 六 tab 全部可切、可截，面板高度随页变化（331 → 475 / 546 / 506 / 537）；

- 「检查更新」真实打了一次 GitHub API 并回到 UI（详见主干报告）；
- **发版链路仍是断的**：本地 1.26.0、远端最新 release 是 1.23.0，所以版本检测对所有人都会显示「已是最新」。
