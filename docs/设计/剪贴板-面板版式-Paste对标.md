# 剪贴板面板版式（对标 Paste）

> 状态：已实现并验收｜日期：2026-11-28｜相关：[Paste 界面取证](/tmp/paste-ref/ANALYSIS.md)、[剪贴板历史-设计规格](剪贴板历史-设计规格.md)
> 本文只记「这一轮把面板改成了什么样、为什么」，键位与数据口径仍在设计规格里。

## 1. 改了什么（一张表）

| 维度 | 改前 | 改后 | 理由 |
|---|---|---|---|
| 面板形态 | 左右各留 20pt 的悬浮窗、底距 12pt、圆角 14 | **通栏横条**：左右贴齐 visibleFrame、底距 8pt、圆角 24 | Paste 是贴屏幕底部的整屏宽横条，通栏后一屏多放半张卡，也不再像一块飘着的对话框 |
| 卡片尺寸 | 卡高 = 卡片区高，宽度被 260pt 截断 → 默认面板下是 260×316 的**竖卡** | 卡高 = 卡片区高 − 顶 8 − 底 24；宽度 = 卡高 × 1.146，上限 320，**封顶后高度一起停住**（320×279） | 1.15 的横卡比例在默认面板高度下根本没生效；只封宽度不封高度会在最高档重新长出竖条 |
| 卡片纵向位置 | 卡片区里垂直居中（上下各 8pt） | **顶部对齐**（顶 8 / 底 24） | 底部那条 24pt 正好给状态胶囊，与 Paste「卡片贴顶、底部留白」同口径 |
| 选中描边 | 2pt 蓝描边画在卡头色带**之下** → 顶部那一圈被整条色带盖掉 | 描边画在**所有内容之后** | 选中卡只剩左右和下有条蓝线，顶上没有，看起来像「描边缺一段」 |
| 星标 | 只在 hover / 选中时显示，点了没反应（整卡单击=粘贴） | hover 常显、**单击即收藏**（命中框 24pt、手型光标、不选中也不粘贴） | Paste 在 hover 时给一个 ⊕ 入口；我们没有 pinboard 数据结构，把它接到已有的「收藏」上 |
| 面板高度 | 只能去设置页拖滑块 | 工具条右端**档位按钮循环三档**（紧凑 264 / 标准 320 / 宽松 420），滑块仍可用 | Paste 的高度三档；卡片尺寸继续由高度推出，不存在第二套「档位直接改卡尺寸」的口径 |

## 2. 几何真源

```
面板（通栏）  宽 = visibleFrame.width，底边 = visibleFrame.minY + 8，圆角 24（内衬 22）
  高度 216…360（默认 264）
  工具条 34pt   筛选芯片 → 搜索框 → 板胶囊 → 计数 → ? → 档位 → 采集
  卡片区 弹性   paddingX 10
     卡片高 = 卡片区高 − 8（顶）− 24（底），夹在 150…279
     卡片宽 = 卡片高 × (227/198)，上限 320；宽到上限后高度一起停（320×279）
     单行横向，间距 12，卡片顶部对齐
```

## 3. 三个档位的实测（1512pt 宽屏 / 2x 截图）

| 档位 | 面板高 | 卡片 | 一屏张数 |
|---|---|---|---|
| 紧凑 | 216 | 172×150 | ≈8.2 |
| 标准（默认）| 264 | 227×198 | ≈6.1 |
| 宽松 | 320 | 291×254 | ≈5.0 |

**为什么整体下移一档**：第一版三档是 264 / 320 / 420（一屏 6 / 5 / 4 张），默认档的卡片
291×254 里常常只放着一行正文、其余一百多 pt 全是空白 —— 空间利用率太低。
现在默认档正好是设计基准卡 227×198（与 Paste 243×212 同量级），一屏比 Paste 还多放小半张。
已有偏好里的 320 是「没人主动选过」的旧默认值，按 `clipboard.panelHeightLayout` v3 一次性
换算到 264；用户自己拖出来的自定义高度（任何 ≠320 的值）原样保留。

面板高度上限同步收到 **360**（= 工具条 34 + 卡片 279 + 上下留白 47）：卡片宽到 320 之后高度就停在同一比例上，
再高的面板只会把那截空白越拉越长（480 时底部留白 135pt）。

档位按钮把高度写进 `clipboard.panelHeight`（仍是高度数值，不是档位名）：用户在设置页拖到 350 再回来，
显示的是「最接近的一档」，不会被吸附或改写 —— 否则拖到 350 下次打开会莫名变 320。

## 4. 从 Paste 学到的 / 明确不抄的

**学**：通栏横条、底部留白、横卡比例、hover 收藏入口、高度三档、选中 2pt 内描边。

**不抄**：

- **pinboard（多板）作为常驻分类轴**：我们的「板」已经是同一个东西，但没有 Paste 那种「拖到 tab 上就归板」的投射，暂不做拖拽投射。
- **搜索默认收成放大镜图标**：我们的搜索框是常驻的，因为面板一开就打字是最常用路径（Tab / ⇧Tab 还挂在类型筛选上）。
- **类型筛选只在搜索态出现**：我们的 chip 行是既有能力，收起来会让 Tab 循环失去落点。
- **卡片头带高 = 卡宽 23.6%**：那是 Paste 把来源色当整块色纸的用法；我们保持 26pt，卡头是标签不是海报。

## 5. 已知取舍

- 通栏后左右贴边，四角圆角会透出桌面；这是 Paste 的观感，不是漏画。
- 鼠标位置策略（`clipboard.panelPosition = mouseLocation`）下不是通栏，退成宽上限 720pt 的小窗 —— 贴着鼠标还铺满全屏会盖住半个屏。
- 卡片宽度上限 360 只在超宽屏触发，常规 14/16 寸屏永远由高度推出宽度。
