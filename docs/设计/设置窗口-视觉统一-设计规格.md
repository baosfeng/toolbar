# 设置窗口视觉统一设计规格

> **何时阅读：** 改设置窗口（`Settings/`）的任何视觉层——令牌、卡片、行、侧栏、字号，或新增设置分类页时。

## 背景

用户反馈：「当前应用的设置页和详情页的设计风格不搭配，需要好好设计一下。」

「详情页」指菜单面板里的**系统二级详情页**（`SystemDetailPaneView+CPU/GPU/Memory/Disk/Process`）——面板设计语言（`PaneCardStyle` + `ThemeStyle` 三主题）成熟度最高的一屏；设置窗口是 760×540 独立窗口，视觉仍停留在建窗时的通用风格包（外部 `--accent #2563eb`、白底 + 灰描边卡）。

原型：`.open-design/settings-redesign/drafts/d-final.html`（A/B/C/D 四版，D 为定稿）；度量与取色对照见同目录 `04-notes.md`；改造前后快照由 `Scripts/measure-settings-style.py` 量测。

## 现状差异矩阵（改造前，取自 DEBUG 离屏快照）

| 维度 | 设置窗口 | 面板 / 系统详情页 |
|------|----------|------------------|
| 取色源 | 系统语义色：`underPageBackgroundColor` / `controlBackgroundColor` / `separatorColor` | `ThemeStyle.color(_:)` 语义角色 |
| 换主题 | **不跟随** | 跟随 Apple / 冷调石墨 / 暖调米白 |
| 卡片 | 白底 `0xFFFFFF` + 1pt 灰描边 + 圆角 10 | cardFill `0xF5F5F7` + 圆角 9 + 0.5pt cardStroke + 顶部 1pt cardHighlight |
| 页头 | 20pt semibold 标题 + 11.5pt 副标题 | 22pt 页头行：11pt 粗体页名 + 10pt 等宽 meta |
| 行 | 行名 13pt / 行值 12pt 等宽 / 行高 ≥40 | 行名 10.5 / 行值 10.5 等宽 / 行高 28 |
| 数值与状态 | 不强制等宽；状态是裸灰字 | 一律等宽 digit + 语义色（ok / warnInk / accent） |
| 侧栏 | 168pt，选中 `accent 14%` 底 | 顶部 pill 分页条，选中 bandFill + accent |

## 统一原则：设置窗口 = 窗口尺度的面板语言

不是把面板 10.5pt 字号搬进 760pt 窗口，而是**同源三件套 + 窗口档尺寸**：

1. **同一令牌源**：设置页所有颜色转发 `ThemeStyle` 角色，不再直接引用系统语义色。
2. **同一卡形**：cardFill 底、圆角 `PaneCardStyle.cardRadius`(9)、`cardStroke` 0.5pt、`cardHighlight` 顶部 1pt；没有白底描边卡。
3. **同一层级逻辑**：页头 → 分组标题 → 卡片（卡头 + 等宽 meta）→ 行（行名 / 等宽行值）；字号按窗口档每级 +1.5pt。
4. **同一状态表达**：权限 / 存储 / 版本 / 采样用 `bandFill` 状态带与页头胶囊，不用裸灰字。
5. **跟随外观**：切主题 / 切渲染档后设置窗口立即重绘（订阅 `AppEvents.appearanceChanged` / `renderTierChanged`）。

## 定稿度量表（实现逐项落值，取自原型 D 版）

| 度量 | 定稿值 | 面板原值 |
|------|--------|----------|
| 窗口 / 侧栏 | 760×540 / 168pt / 项高 30 / 字号 12 / 图标 14 | — |
| 内容区内边距 | 16pt | 12pt |
| 页头标题 / 说明 | 17pt 粗 / 11.5pt 次级 | 11pt 粗（22pt 行高） |
| 分组标题 | 11.5pt semibold `textSecondary`，中文不转大写 | — |
| 卡片圆角 / 描边 / 高光 | 9pt / 0.5pt `cardStroke` / 顶部 1pt `cardHighlight` | 9 / 0.5 / 1 |
| 卡内边距（左右 / 上下） | 10pt / 6pt | 7 / 4 |
| 行高 / 行名 / 行值 | 32pt / 12pt / 11.5pt 等宽 | 28 / 10.5 / 10.5 等宽 |
| 卡头高度 / 字号 / meta | 13pt / 11.5pt 粗 / 10.5pt 等宽 `textTertiary` | 13 / 11 / 10 |
| 卡片间距 / 分组间距 | 10pt / 12pt（上）6pt（下） | 4 / — |
| 行分隔线 | 相邻行之间 1pt `hairline`（只画在卡内边距以内） | 卡内不画线 |
| 状态带 / 页头胶囊 | 20pt / 圆角 6 / `bandFill` | 20 / 6 |
| 控件高（下拉 / 按钮 / 分段） | 22pt | — |

**与面板的两处有意偏离**（都要在实现注释里写明理由）：

- 卡内画 1pt 行分隔线：设置页每行是**独立设置项**（开关 / 下拉 / 可编辑值），扫读靠横向对齐；面板卡内行是同一指标的多个读数，不画线才不碎。
- 多一层「分组标题」：一屏 5 组内容需要分区，它的字号仍是面板「11pt 粗 + 次级色」同一档。

## 页头状态胶囊口径

只在有真实状态的页出现，一个胶囊表达「一个主语 + 一个状态」，状态点只有 ok / warnInk / ghost 三种：

| 页 | 文案 | 数据来源 |
|----|------|----------|
| 通用 / 关于 | 不放 | — |
| 外观 | `Apple · 极致` | `ThemeID.displayName` + 渲染档名 |
| 额度 Provider | `1 个已配置 · 查询中` | 已启用且已配置的实例数 + 查询态 |
| 剪贴板 | `已授权 · 386 条` | 剪贴板访问授权态 + 条目数 |
| 截图与贴图 | `JPEG · 质量 0.90` | `SnipPreferences` 输出格式 + JPEG 质量 |
| 局域网互传 | `可接收 · 0 台在线` | 监听态 + 发现设备数 |
| 通知与音效 | `已授权 · 音量 60%` | 通知授权态 + 应用内音量 |
| 系统 | `采样 1.0 s` | `SystemMonitorPreferences.sampleInterval` |

## 颜色映射（设置页用途 → 主题角色）

| 用途 | 角色 |
|------|------|
| 窗口底 / 内容区底 | `surface` |
| 侧栏底 | `surface`（右侧 0.5pt `hairline` 竖线） |
| 卡片底 / 描边 / 高光 | `cardFill` / `cardStroke` / `cardHighlight` |
| 行分隔线 / 侧栏竖线 | `hairline` |
| 悬停 / 选中底 | `selectedFill` |
| 状态带 / 胶囊底 | `bandFill` |
| 文字三档 | `textPrimary` / `textSecondary` / `textTertiary` |
| 强调（选中文字、链接、开关开态） | `accent` |
| 达标 / 告警 / 停用 | `ok` / `warnInk` / `ghost` |
| 破坏性动作（清空…） | `SettingsStyle.destructive`（= `NSColor.systemRed` 单一出口，**不进 ThemeRole**，红的语义与主题无关） |

## 实现落点（文件边界）

1. `Settings/SettingsTheme.swift`（新增）：令牌层——颜色转发 `ThemeStyle`、定稿几何与字号常量、卡片背景绘制、状态带与胶囊组件。
2. `Settings/SettingsComponents.swift`：`SettingsStyle` 改为转发令牌；`SettingsCardView.draw` 换卡形；`SettingsPageStack` 页头 + 分组标题 + 页头胶囊挂载；`SettingsRowView` 行高与字号；`SettingsDividerView` 走 `hairline`。
3. `Settings/SettingsWindow.swift`：窗口底 `surface`、侧栏三段分组与选中态、订阅外观变更重绘。
4. 组件族：`SettingsOrderedCard`（排序按钮色）、`SettingsNotificationEventCard`、`SettingsProviderRow*`、`SettingsSharedComponents`（状态点 / 链接按钮）随令牌改色。
5. 各 pane：只替换直接写死的系统色与局部字号，并接页头胶囊数据源；不重排信息结构。

## 验收标准

1. **跟随主题**：三套主题 × 浅深 × 九分类快照全部生成；卡片底 / 窗口底 / 文字色随主题变化（`Scripts/measure-settings-style.py` 输出表格，Apple 浅色卡底 `0xF5F5F7`、石墨 `0xECF0F6`）。
2. **与面板同源**：卡片圆角 9、行高 32、卡头 11.5 粗、行名 12 / 行值 11.5 等宽、内边距 10/6 逐项一致。
3. **无回归**：`swift build` 0 error；`TestRunner` 全绿；大文件门禁通过；开关 / 下拉 / 快捷键录制状态文本自证不变。
4. **对比证据**：改造前后同页截图并排（含深色）+「改前 → 改后」度量数字表。

## 已知偏离（有意为之）

1. **控件仍用系统自绘外观**（NSSwitch / NSPopUpButton / NSSlider / 输入框 bezel）：原型里是全自绘。保留系统控件保住了键盘操作、焦点环、输入法与无障碍；统一靠高度（22pt）、圆角与配色，不重画控件。
2. **卡内 1pt 行分隔线取 `hairline` 100%**（不是 40%）：40% 混在 `cardFill` 上仅差 5 级灰度、截图不可辨；100% 与旧 `separatorColor @0.6` 视觉强度相当。
3. **信息结构未重排**：排序卡「第 N 项」仍在行副标题（原型改为行内 meta）、关于页版本号仍在卡内、Provider 卡头右侧「查询节奏」未新增槽位、快捷键录制沿用既有控件 —— 本轮只改视觉层，结构变化留待单独一轮。
4. **页头胶囊三处口径调整**（数据源拿不到就不硬造）：剪贴板用「已允许 · N 个文件」（历史条目数在组合根数据库，未扩协议）；互传只有「N 台在线」（`TransferService.isRunning` 在 actor 内，同步取会出假状态）；截图本机真实偏好是 PNG 故只显示「PNG」。
5. **侧栏首段段头上间距取 10**（原型 4 + 品牌 10 = 14）：差 4pt 不可辨，统一一档少一个特例。
6. **圆角量测近似**：`measure-settings-style.py` 量到 6 是抗锯齿 + 渲染倍率偏差；精确值以 `SettingsSkeletonMetrics.cardRadius = 9` 为准，与原型截图角部像素逐点比对一致。
