# 截图工具条文字提示与自定义

> **何时阅读：** 改截图工具条的排版、文字提示、设置项，或新增可自定义维度前。

## 背景

一级工具条此前只有图标：工具、颜色、线宽、以及「更多」入口都没有任何文字，
用户只能靠猜或背快捷键。Snipaste 的做法是「图标常驻 + 鼠标悬停时弹出名称提示」，
条高不变；本方案默认对齐该做法，并把工具条的可自定义维度全部收进设置页。

## 文字提示三档

| 档位 | 条高 | 观感 | 适用 |
|------|------|------|------|
| 仅图标 `iconOnly` | 40pt | 与旧版一致，无任何文字 | 熟手 / 追求极简 |
| 悬停提示 `hover`（默认） | 40pt | 悬停按钮提亮 + 上方气泡「名称 · 快捷键」 | 日常使用 |
| 常驻标签 `always` | 50pt | 图标下方 9.5pt 中文名常驻 | 记不住图标 / 演示 |

气泡画在工具条上方的 28pt 留白里（`SnipToolBarLayout.bubbleSpace`），不压选区内容；
二级面板展开时气泡自动隐藏（`isPanelOpen`），否则气泡会露在面板底下。

- 气泡文案：工具写中文名（矩形 / 箭头 / 文字 / 马赛克 …），颜色写「颜色 · 红色」，
  线宽写「线宽 · 4 pt」，动作为「取消 Esc」「复制 ⌘C」等；
- 二级面板同一档位：面板条目也走悬停气泡 / 常驻标签，线型写「实线 / 虚线」，
  透明度写「不透明 / 半透明 / 淡」。

## 可自定义维度

设置页「截图与贴图 › 工具条显示 / 排列顺序 / 常驻工具 / 输出动作」：

| 维度 | 可改内容 | 约束 |
|------|----------|------|
| 文字提示 | 三档之一 | — |
| 位置 | 自动 / 恒选区下方 / 恒选区上方 | 一律夹进屏内 |
| 组显隐 | 标注工具 / 颜色 / 线宽 / 输出动作 | 至少保留一组 |
| 排列顺序 | 四组上移下移 | 顺序唯一且完整 |
| 常驻工具 | 10 个工具任选 | 至少保留 1 个；其余进「更多」面板 |
| 输出动作 | 取消 / 复制 / 保存 / 贴图 | 至少保留 1 个 |

写偏好即生效：下一次截图按新配置上屏，不需要重启。

## 数据流

```
设置页（SettingsCapturePane+ToolBar）
   └─ SnipToolBarConfigurationResolver.persist → 偏好 5 键
覆盖层（SnipController+Overlay）
   └─ SnipToolBarConfigurationResolver.load → SnipToolBarConfiguration
        → SnipToolBarView(configuration:) → SnipToolBarLayout.plan(config:)
```

- 键名集中在 `SnipToolBarPreferenceKey`（`snip.toolbar.*`），设置页与覆盖层共用同一份定义；
- 解析规则收在 Core 纯函数 `SnipToolBarConfigurationResolver`：缺键回落默认、非法项逐项丢弃、
  结果统一过 `normalized`（至少一组 / 一个工具 / 一个动作），因此任何存储脏数据都能上屏；
- 读路径不写回默认值：没设置过的用户将来默认值调整时能跟着变。

## 布局口径

- 宽度与按钮位置由 `SnipToolBarLayout.plan(config:)` 一次算完，左右内边距恒等；
- 组顺序、组显隐直接决定 `orderedGroups` 与 `dividerXs`：空组既不占宽也不发分隔线；
- 常驻工具顺序即工具条上的顺序（新选的追加到最右，不让按钮跳位）。

## 取证方式

- 工具条离屏渲染：`NM_SNIP_TOOLBAR_SNAPSHOT_DIR=/tmp/x /Applications/NetworkMonitor.app/Contents/MacOS/NetworkMonitor`
  → `toolbar-hover-tool.png`（悬停气泡）/ `toolbar-labels.png`（常驻标签）/ `toolbar-icononly.png`（老外观）/
  `toolbar-custom.png`（自定义排列）/ `panel-*.png`（二级面板）；
- 覆盖层：`NM_SNIP_OVERLAY_SNAPSHOT_DIR` → `overlay-selected.png`（含悬停气泡的实际观感）；
- 设置页：`NM_SNAPSHOT_DIR` → `settings-capture-{light,dark}.png` 与控件状态文本
  `settings-toolbar-states.txt`（勾选态与偏好真值并排，用于核对「界面 vs 实际配置」）。

> 快照必须跑 .app 包内的可执行文件：裸二进制会崩在 `bundleProxyForCurrentProcess is nil`，
> 见 [快照取证需打包成 app](../踩坑/构建/快照取证需打包成app.md)。
