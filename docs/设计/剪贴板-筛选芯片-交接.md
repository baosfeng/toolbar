## 已确认事实

- `ClipboardFilter` 从 App 搬到 UI 层后，Tab 循环口径改由 `ClipboardFilterCycle` 表达（只轮换类型芯片，来源/日期保留）。
- 芯片行排版不变量：`rightEdge - originX <= available`；省略徽标放不下时撤回最后一枚芯片给它让位（不静默丢芯片）；可用宽为 0 时整行让位（不出现按钮）。
- 480pt 窄面板：芯片行整行让位，搜索框回到左内边距且不低于 300。640pt：搜索框取到上限 420（原先被 160pt 分段控件占住）。
