# 剪贴板对标 OneClip 第二批调研证据

> 目的：为[第二批增量设计规格](../设计/剪贴板对标-OneClip-第二批增量设计规格.md)提供可复核的对标证据，逐条带 `文件:行号`。
> 基线：OneClip 快照 `65926e3`（`/tmp/OneClip/src/OneClip/`，简写 **OC:**）；本项目 main @ `5657384`（简写 **TB:** = `NetworkMonitor/Sources/`）。
> 复核方式：OneClip 侧 `sed -n '<行号>p' <文件>`；本项目侧同样。
> 与[第一批调研结论](../调研/剪贴板对标-OneClip-调研结论.md)的关系：那份冻结的是第一批三项，本文只记第二批新增证据，不重复。

## 1. 判定口径

三档：**领先**（我们已更好，不动）· **持平**（语义不同但都成立）· **缺失**（OneClip 真实现、我们确实没有）。第四类**不计入判定**：OneClip 有定义但 **callers = 0**（死代码），等于未实现，列在第 4 节。

## 5. 结论

第二批取三项（设计规格第 2 节）：**A 图片格式兼容（P0）** · **B 缩略图后台解码（P1）** · **C 面板交互补齐（P2）**。其余缺口（9 类 kind、面板读库后台化、HTML 富文本、磁盘容量上限）进设计规格第 3 节 backlog，理由逐条在表内。
