# Snipaste 免费版功能 · 实施计划

> 范围：只做 Snipaste **免费版**能力（截图 + 标注 + 贴图固定 + 内容源 + 设置），**专业版功能全部不做**（元素检测、超级截屏、二次编辑、多选分组、Solo、背景模式、OCR、触发角、任意命令热键等）。
>
> 依据：[Snipaste 功能调研与实现评估](../调研/Snipaste-功能调研与实现评估.md)。总工时 **105.5 人日**，单人 + AI 辅助约 **13–14 周**；两人并行（标注线与贴图线）可压到 **10–11 周**。

## 二、工程化决定

系统类型：**macOS 客户端 App**（菜单栏常驻 + 全局热键 + 覆盖层 + 浮窗）。

| 能力 | 决定 | 程度 | 依据 |
|---|---|---|---|
| 生命周期与状态恢复 | 做 | App 被 kill 后贴图不恢复（与 Snipaste 一致），偏好与热键必须持久 | 贴图是临时工作态 |
| 权限与隐私 | 做 | 录屏 + 辅助功能，缺失时降级并引导，不静默失败 | TCC 是主路径门槛 |
| 版本兼容 | 做 | 保留 Package.swift 的 macOS 14 下限；Snip 内部按 14.4 / 15.2 / 26 三档分支 | 不破坏既有模块 |
| 崩溃上报 | 省 | 本地自用，日志用既有 LoggingService | 无分发需求 |
| 埋点 | 省 | 同上 | — |
| 弱网/离线 | 不适用 | — | 纯本地 |
| 多语言 | 省 | 仅中文 | 自用 |

## 五、M1 任务拆解（可直接派发）

| 任务 | 内容 | 验收 |
|---|---|---|

**冒烟清单（每次发布前手动过一遍）**

1. F1 截图：拖选 → ⌘C → 粘贴到任意输入框，图像完整
2. 窗口检测：按 Tab 切到检测态，鼠标悬停桌面窗口有蓝色高亮，单击即框选
3. 标注：矩形 / 箭头 / 画笔 / 马赛克 / 文字各画一个 → ⌘C，粘贴后标注在图上
4. 贴图：F3 贴一张图 → 拖动、滚轮缩放、⌃滚轮调透明度、按 1 与 3 旋转镜像、Esc 关闭后 F3 恢复
5. 隐藏全部：⇧F3 两次，贴图消失再出现
6. 延时截图：⌥⇧D 后 3 秒自动进入选区
7. 内容源：复制一段文字、一个文件、一个色值 `#FF0000`，分别 F3
8. 设置窗：⌥⇧, 打开，改不透明度后关掉再开，值保持
9. 历史联动：⌥⇧V 打开历史，右键任一卡片「贴到屏幕」
10. 多屏：外接屏上重复 1 与 4，贴图不模糊、不跑位
