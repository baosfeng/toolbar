## 一、已修复（本轮）

### P0 打包脚本杀进程连坐，新版本静默不生效

- 位置：`NetworkMonitor/Scripts/build-app.sh` 部署段。
- 实测：`pgrep -f NetworkMonitor` 命中多行（另一 agent 的 `swift-build --package-path .../NetworkMonitor/.build`、
  编辑器语言服务、shell 自身），把多行 PID 整段传给 `kill` 报
  `arguments must be process or job IDs`，被 `|| true` 吞掉后脚本继续
  `rm -rf /Applications/NetworkMonitor.app`；旧实例存活并持着已删 inode，两个实例共用一个 `monitor.db`。
- 改法：判据收敛为「`/Applications/<App>.app/Contents/MacOS/<App>` 绝对路径完全匹配」，
  逐个 PID 终止、每轮重新查存活、仍有存活则 `exit 1` 中止部署。
- 详见 [打包脚本按名字杀进程连坐](踩坑/构建/打包脚本按名字杀进程连坐.md)。

### P1 SQLite 绑定文本悬空（写入脏数据/丢数据）

- 位置：25 处 `sqlite3_bind_text(..., -1, nil)`，出处是 `(value as NSString).utf8String`。
- 实测：把析构器改回 `nil` 后，剪贴板**第一条**插入即失败（写入后按 id 回读为 `nil`），
  不是偶发而是稳定复现，只是内存没被立刻复用时才看不出来。
- 改法：新增 `sqlite3_bind_text_copy`（`SQLITE_TRANSIENT`）与 `sqlite3_bind_text_or_null` 作为唯一入口，
  25 处全部迁移；`sqlite3_open` 的路径改用 `withCString`。
- 回归：`runClipboardBindingLifetimeTests`（24 条不等长文本写入后逐条回读，校验文本/哈希/来源不串味）。
- 详见 [SQLite 绑定传 nil 不复制内容](踩坑/构建/sqlite绑定传nil不复制内容.md)。

### P1 日志把配对 PIN 与用户路径广播给本机所有进程

- 位置：`OSLogLogger` 一律 `%{public}@`；写进去的有 4 位配对 PIN、用户主目录绝对路径（数据库/接收目录/
  贴图与截图保存路径/DSH 会话文件）。
- 改法：新增 `LogRedaction`（`path` / `pin` / `secret`），12 处敏感日志点全部改走它；
  `OSLogLogger` 默认 `minLevel` 从 `.debug` 改为 `.info`（与类文档一致）。
- 回归：`runLogRedactionTests`。
- 详见 [OSLog 的 public 字段全本机可读](踩坑/运行时/OSLog的public字段全本机可读.md)。

### P1 额度凭据明文存偏好 plist —— **已改回，钥匙串方案实测不可行**

- 位置：`PreferencesBillingCredentialStore` 直接写 `UserDefaults`，全仓无 Keychain 用法；
  存的是可直接冒用的 Ollama API Key 与 Open Design session cookie。
- 试过的改法：`SecretStorage` 协议 + `KeychainSecretStore`（generic password / AfterFirstUnlock）。
- **实测失败**：本项目用自签名证书或 ad-hoc 回落，**每次重建签名身份都会变**，而钥匙串 ACL
  按代码签名绑定。身份一变，`SecItemCopyMatching` 就弹「NetworkMonitor 想要使用钥匙串中的
  机密信息」并**阻塞调用线程**——`sample` 抓到主线程停在 `SecItemCopyMatching`，
  菜单栏 App 启动即卡死（实测已回滚）。
- 最终落地：**本地加密存储** `EncryptedSecretStore`——AES-GCM 密文写进偏好存储，
  密钥由「本机硬件 UUID + `~/Library/Application Support/macMonitor/credentials.key`
  （0600，首次使用生成）」两段材料经 HKDF-SHA256 派生，缺一不可；历史明文在读取时
  **就地加密回写**（值不变，不要求用户重填）。钥匙串保留为显式可选，启用前提是稳定签名身份。
- 附带修掉的真实缺陷：搬迁逻辑在「秘密存储与偏好共用底层」时会把读到的凭据当遗留明文删掉；
  现以 `SecretStorage.sharesStorageWithPreferences`（**协议要求**，扩展默认实现不进 witness table）
  区分，并有 `runCredentialStorageSafetyTests` / `runCredentialMigrationTests` 锁住。
- 实测：偏好里两条凭据均变为 `enc:v1:…`，明文特征命中 0；同机解密可还原（317 / 57 字符）。

> 能力边界（需知悉）：加密挡的是**明文外泄**（`plutil -p`、备份同步、误发文件、日志截图）。
> 同用户身份的恶意进程仍能同时读到 plist 与密钥文件——要防这一层只能用钥匙串
> （需稳定签名证书）或用户口令（需每次输入）。

### P1 CI 从不测试本机唯一可用的构建路径

- 位置：`ci.yml` 三条命令无 `--build-system native`，`release.yml` 显式 `BUILD_SYSTEM: default`，
  而本机文档与项目 skill 强制 native —— 两条路径各自只验证一半，CI 绿不等于本机能出包。
- 改法：`ci.yml` 全部改走 native；`release.yml` 新增「tag ↔ `CFBundleShortVersionString`」断言
  （实测 tag=1.13.0 / plist=1.12.1 时按预期 exit 1）。

### P1 互传集成测试固定端口导致的假红

- 位置：`TransferRetryIntegrationTests` 写死 `[54101, 54102, 54103]`。
- 实测：本机 54101 被 VS Code 代理连接占用、54102 被 ApexCore 占用 →
  `listenerUnavailable("Address already in use")`，测试红但代码没坏。
- 改法：每次运行随机取 20000–42000 的连续 16 个候选端口。

### P1 Token 页把「索引失败」显示成「还没有可统计的会话」

- 位置：`TokenPaneView.applyState()` 只区分 available / empty / indexing，
  `HarnessIndexingState.failed` 在 `MenuPanel/` 下**没有任何分支消费**。
- 改法：空态区分「失败」与「没数据」并显示原因；有数据但索引失败时把原因挂到索引标签。

### P1 Token 二级页 Esc 直接收起整个面板

- 位置：`MenuPanelView.keyDown` 的 Esc 只处理系统页；`TokenPaneView.focusableRows` 在二级页时返回空数组，
  返回按钮也不在遍历里 → 键盘用户进得去出不来。
- 改法：Esc 与系统页一致先返回；把「‹ Token」包装成可聚焦行交给焦点遍历。

### P1 可点行与分页条对辅助技术不可用

- 位置：`MenuPanelRow`（剪贴板条目、传送设备与任务、额度卡头、Token 卡片、表头「全部」的基类）
  只设 label，无 role、无 `accessibilityPerformPress`；`MenuTabBarView` 六段全自绘，
  对读屏只是一块空白。
- 改法：行基类补 `.button` 角色与激活转发；分段条为每段生成可激活的虚拟元素。

## 二、已知未修（有意保留，需决策）

| 项 | 为什么不动 |
|---|---|
| bundle id 用模板占位 `com.example.NetworkMonitor`（`build-app.sh`） | 换 id 会让 TCC 授权（屏幕录制 / 辅助功能 / 本地网络）与登录项全部失效，用户需重新授权。属于**需要用户点头才能迁**的破坏性变更 |
| 凭据加密挡不住同用户恶意进程 | 密钥材料在本机（机器 UUID + 0600 密钥文件），同用户进程可同时读到密文与密钥；要防这一层需钥匙串（要稳定签名证书）或用户口令 |
| Token 时间窗口固定 `Asia/Shanghai` | 改跟随系统时区会让历史「今日」口径整体平移，用户会看到数字突变。要做应作为一次显式口径变更并告知 |
| 大文件门禁被「拆成多个恰好不超限的文件」绕过（如 `SystemPaneView*` 14 文件 2542 行） | 门禁本身只能判单文件；真正的治理是按职责重划模块，属独立一轮重构，不应夹在体检修复里做 |
| 23 个文件贴在阈值 90% 以上（4 个 99%+） | 同上；现在动它们只会制造无意义的重新拆分 |
| 设置页「数值单位」只作用于 Token / 额度页 | 网络页柱状图标签位只有十几 pt，换中文口径会被裁；已把生效范围写进文案，不强行统一 |
| 截图失败等 `catch {}` 空吞异常 | 逐个核对风险后保留：这些都是「用户已经看到失败弹窗 / 降级为 nil」的路径，补日志反而是噪音 |
