# 变体差异

同一指标集、同一数据快照（2026-09-07 ~ 2026-10-24，34 个有数据日），两种信息层级。

## a · 总览优先
- 首屏顺序：分段条 → 页头 → 范围切换 → 三列平权指标（未缓存输入 / 输出 / 缓存读）→ 本周与累计两行对照 → 缓存命中率细条 → 按天柱状 → 按项目（Top5）→ 按模型（Top4）。
- 取舍：日常「今天/本周烧了多少」一眼可读，三项指标等权，命中率只占一行；分布区靠下，需要滚动。
- 适合：把 Token tab 当仪表盘用，打开先看数字再看结构。

## b · 趋势优先
- 首屏顺序：分段条 → 页头（范围切换收进同一行）→ 三项合计 hero + 三格占比 chips → 命中率环形仪表 + 口径说明 → 大图趋势（柱/折线可切）→ 本周/累计 → 按项目/按模型（各 Top3 可展开）。
- 取舍：先看走势与结构占比，绝对数字下沉为 chips；分布默认只露 3 行，展开才见全部；命中率用环 + 一段解释替代进度条。
- 适合：排查「哪几天/哪个项目用量异常」，或向别人解释消耗结构。
