# 面板五页风格统一 — 设计规格

> 起因：五个 tab（网络 / 剪贴板 / 传送 / 额度 / Token / 系统）各自按当时需求单独成型，
> 同一面板切页时能看出多套公式。本规格定稿一套令牌与版式骨架，五页只填内容、不再各画一遍壳。

## 一、现状差异（量测口径：DEBUG 快照 320×N，浅色）

| 项 | 网络 / 剪贴板 / 传送 | 额度 / Token | 系统 |
|---|---|---|---|
| 分区标题 | 10pt 半粗 | 11pt 粗体 | 10pt 半粗 |
| 行名 / 数值 | 12pt / 12pt 等宽 | 10.5pt / 10.5pt 等宽 | 9–10pt |
| 卡片底 | `subtleFill`（半透明灰，0xEDEDED） | `cardFill` 实色 0xF5F5F7 | 语义洗色 `cardCPU` 0xEAEFF6 … |
| 卡片圆角 | 8pt | 9pt | 8pt |
| 卡片内边距 | 8pt | 7 / 4pt | 6pt |
| 列表行高 | 32pt（剪贴板 / 传送）/ 28pt（进程） | — | — |
| 页头行 | 无 | 22pt（额度 / Token） | 无 |
| 页脚状态带 | 无（网络页只有 Wi-Fi 条） | 20pt，底 0xEEEFF2 | 20pt，底 0xF0F0F4 |
| 状态带键值字号 | — | 10pt / 10.5pt 粗 | 9pt / 9pt |
| 页面主栈间距 | 10 / 6 | 4 | 8 |

页面高度（统一前 → 统一后）：网络 516 → 497、剪贴板 282 → 255、额度 259、Token 520、系统 495 → 498。

## 三、版式骨架（五页同一顺序）

```
页头行 PaneHeaderRowView（22pt）：页名 · 弹簧 · 口径文字 · 动作槽（刷新 / 分段）
内容栈（间距 4pt，卡片依次排布）
页脚状态带 PaneStateBandView（20pt）：键 + 值 ×N，右端弹簧
```

- 页名：网络「网络」、剪贴板「剪贴板」、传送「传送」、额度「额度」、Token「DSH · N 会话」、系统「系统」。
- 页脚口径按页给：网络「今日总量 / 进程数 / 采样」、剪贴板「条目 / 上限」、传送「设备 / 任务」、
  额度「Provider / 最近刷新 / 单位」、Token「峰 / 昨 / 索引 / 缓存」、系统「SoC / 电池 / Wi-Fi / 估功耗」。
- 有二级页的（系统 / Token）页脚跟着二级页走：二级页自带页脚或返回条，不重复画。

## 四、有意保留的偏离（不统一，需在代码注释写明理由）

| 页面 | 偏离 | 理由 |
|---|---|---|
| 系统 | 五张卡的 `wash` 语义分族底色（0xEAEFF6 / 0xEEEFF6 / 0xEBF1F2 / 0xF3EDEC / 0xF2EEEC） | 该页的表达手段是「一族一色」，用户已按 v2 定稿；只统一圆角 / 内边距 / 字号层级 |
| 系统 | `microFont` 9pt / `tinyFont` 8.5pt | 五卡 + 四联 + 状态带一屏 495pt，字号再抬一档装不下；属于密度取舍 |
| Token | 四族卡底色（`uncachedCardFill` 等）与 Hero 24pt | 四族分色与 Hero 是该页的信息架构，已定稿 |
| Token | 四屏外框高度恒 409pt | 切屏时 popover 不跳高跳低 |
| 网络 | 下行 `systemGreen` / 上行 `systemOrange` | 语义色不属于卡片语言；数值与折线配色是这张卡的表达 |

## 五、验收

1. `NM_SNAPSHOT_DIR` 快照逐页看图：五页第一行都有一条 22pt 页头，末行都有一条 20pt 状态带。
2. 像素量测：卡片底统一 0xF5F5F7（浅），圆角 9pt，左内边距 12（面板）+ 7（卡内）。
3. `swift run TestRunner` 全绿；`bash Scripts/check-file-size.sh` 无新增超限文件。
4. 网络页在加页头 + 状态带后总高 ≤520，不触发外框滚动。
