# 剪贴板底部详情区

> **何时阅读：** 改剪贴板面板的分段布局、面板高度上下限、详情区排版或读屏口径；
> 或者想知道「悬停看全文」为什么换成了常驻详情区。

## 为什么换

早期做法是悬停 0.45s 在卡片旁弹一个全文浮层。它带来两类代价：浮层要么拦鼠标（挡住卡片点击与右键菜单），
要么不拦鼠标（内部滚动就失效，见[踩坑](../踩坑/运行时/忽略鼠标事件的浮层自己收不到滚轮.md)）；而且浮层是独立子窗口，
鼠标一动就可能留下收不掉的残影。

现在的做法是把完整内容变成面板自己的一块区域：**面板底部常驻详情区**。卡片 hover 只保留提亮 + 描边，
选中项（点击 / 方向键 / 过滤变化）一变，详情区就地刷新。浮层实现已删除。

## 四段几何

面板自上而下切四段（翻转坐标，y 向下），取值全部来自 `ClipboardPanelLayout`：

| 段 | 高度 | 说明 |
|----|------|------|
| 工具条 | 32 | 搜索框 / 类型过滤 / 采集 / 「?」帮助；控件高 24、间距 8、左右内边距 10 |
| 卡片区 | 弹性 | 卡片高 198 + 上下留白 6；面板高度变化只作用在这一段，卡片在区内垂直居中 |
| 详情区 | 102 | 1pt 分隔线 + 内容 101pt（上下内边距 8、元信息行 13、间距 4、正文可视高 `bodyHeight`） |
| 提示行 | 24 | 件数计数 / 栈进度 / 按键提示 / 权限入口，文案行高 16 |

面板高度因此满足：`minPanelHeight = 工具条 32 + 整卡 198 + 留白 6 + 详情区 102 + 提示行 24 = 362`，
上限 `maxPanelHeight = 480`，默认值取下限。三个数都由几何常量算出，`ClipboardPreferences.heightRange` 直接引用同一份范围，
所以设置页的高度滑块不会拖到「卡片被裁」的位置。

工具条与提示行的横向分配同样是纯函数（`toolbarMetrics` / `footerMetrics`）：搜索框 300–420 弹性、类型过滤定宽 160、
「?」定宽 24；提示行在窄面板下优先让栈进度退出，计数与按键提示不先消失。

## 为什么高度恒定，不按内容算

详情区高度是常量，与「有没有选中」「正文多长」都无关：

- **切条目时面板不跳**：按内容算高度会让面板在选中长文本时瞬间长高、选中短文本时缩回，卡片区里的卡片随之上下位移，
  连续按方向键翻条目就是连续抖动；
- **卡片区是唯一的弹性段**：把高度波动全部收进卡片区，工具条与提示行的位置在会话内完全固定，点击目标不会跑；
- **超长内容不需要更大空间**：正文给了固定的可视高度（约 4 行 12.5pt），超出部分由详情区自己的 `NSScrollView` 滚动，
  换条目时正文滚回顶部，不会接着上一条的滚动位置。

务实的结果：信息密度靠「卡片区可调 + 详情区恒定」两者配合，用户想要更大的卡片区就拉高面板，而不是让详情区跟着内容变形。

## 版式与内容口径

版式（翻转坐标，自上而下）：1pt 分隔线 → 右上角元信息小字 → 正文。

- **元信息**：复制次数 · 类型 · 相对时间 · 来源 App，缺项自动跳过、不留空档；无选中时整行隐藏；
- **正文**：文本条目给完整正文（不提前截断，否则用户再也看不到后半段），图片条目给尺寸摘要，缺正文时回退到摘要；
- **空态**：无选中时显示「选中一条查看详情」，用次要色，读屏只念这句空态文案。

这些规则都在 `ClipboardDetailStrip`（`NetworkMonitorUI`）里，视图 `ClipboardDetailStripView` 只取数与排版，
于是「文案怎么拼」「可视高度多少」由 `TestRunner` 直接断言，不必起界面。

## 读屏口径

整块详情区上报**一个** `group` 元素，标签为「详情：<正文>。<元信息>」；空态时只念空态文案本身。

理由：正文与元信息是同一件事的两半，逐段上报会让读屏把同一条内容念两三遍；而卡片是一个元素、详情区是一个元素，
读屏从卡片滑到详情区正好是「这是哪条 → 这条的完整内容」的自然顺序。

## 缩略图翻正

同一轮还修了卡片缩略图在 flipped 上下文里上下颠倒的问题：`DrawnUnflip` 给出目标矩形中线上的镜像变换，
`DrawnInk.withUnflippedIfNeeded` 施加，缩略图的 `drawAspectFill` 与文件条目的来源 App 图标两处套用。
翻正只挡位图、不整段翻——文字绘制自己会翻正，整段翻会把文字翻过去。成因与验证见
[flipped 上下文里的位图绘制要翻正](../踩坑/运行时/flipped上下文里的位图绘制要翻正.md)。
