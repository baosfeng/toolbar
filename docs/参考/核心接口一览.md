# 核心接口一览

> ⚠️ **何时阅读：** 当你需要了解本项目公开的核心类、方法签名和参数说明时，请阅读本文档。

## NetworkSpeedMonitor

网络接口字节计数器读取与速度计算核心类。

**源码位置：** `NetworkMonitor/Sources/NetworkMonitor/NetworkMonitor.swift`

### 属性

| 名称 | 类型 | 访问级别 | 说明 |
|------|------|---------|------|
| `downloadSpeed` | `Double` | `private(set)` | 当前下载速度（字节/秒） |
| `uploadSpeed` | `Double` | `private(set)` | 当前上传速度（字节/秒） |
| `totalRx` | `UInt64` | `private(set)` | 自启动以来总接收字节数 |
| `totalTx` | `UInt64` | `private(set)` | 自启动以来总发送字节数 |

### 方法

| 方法 | 说明 |
|------|------|
| `func poll()` | 采集当前网速，更新 downloadSpeed/uploadSpeed。应周期性调用（如每秒一次） |

## MenuBarManager

菜单栏显示管理类，继承自 `NSObject`。

**源码位置：** `NetworkMonitor/Sources/NetworkMonitor/MenuBarManager.swift`

### 初始化

| 初始化器 | 说明 |
|---------|------|
| `init()` | 创建菜单栏项目、加载每日流量、设置菜单/定时器/本机监控 |

### 方法

| 方法 | 说明 |
|------|------|
| `private func setupMenu()` | 设置 NSStatusItem 和下拉菜单（标题栏、网络信息、活跃进程、电池、本机监控、流量汇总） |
| `private func setupTimer()` | 创建 1 秒间隔的 Timer，使用 `.common` mode |
| `private func setupMacMonitor()` | 初始化并启动本机监控子系统（DatabaseManager、EventMonitor、KeyPressMonitor、SystemSampler） |
| `@objc private func update()` | Timer 回调，更新菜单栏和下拉菜单的网速、电池、进程、每日流量 |
| `private func formatSpeedShort(_ bps: Double) -> String` | 格式化速度为短字符串（如 "1.2M"、"340K"） |
| `private func loadDailyTraffic()` | 加载/初始化每日流量追踪基准值 |
| `private func updateDailyTraffic()` | 检查日期变更，切换并保存每日日志 |
| `func flushBeforeQuit()` | 退出前刷新数据库缓冲区并关闭连接 |
| `@objc private func toggleDetailPanel()` | 双击打开/关闭详情面板 |
| `@objc private func toggleLaunchAtStartup()` | 切换开机自启动（SMAppService） |

## 数据结构

### ProcessNetUsage

```swift
struct ProcessNetUsage {
    let name: String       // 进程名
    let pid: Int32         // 进程 ID
    let bytesIn: UInt64    // 下行速率（字节/秒）
    let bytesOut: UInt64   // 上行速率（字节/秒）
    var total: UInt64 { bytesIn + bytesOut }  // 总速率
}
```

### TodayStats

```swift
struct TodayStats {
    let activeSeconds: TimeInterval     // 活跃时间（秒）
    let keyPressCount: Int              // 击键总数
    let screenOnSeconds: TimeInterval   // 亮屏时间（秒）
    let screenOffSeconds: TimeInterval  // 息屏时间（秒）
    let appRanking: [AppUsage]          // 应用排行
    let cpuUsage: Double                // CPU 使用率
    let memoryUsedMB: Int               // 内存使用（MB）
    let memoryTotalMB: Int              // 总内存（MB）
    let netDownloadSpeed: UInt64        // 网络下载速率
    let netUploadSpeed: UInt64          // 网络上传速率
}
```

### AppUsage

```swift
struct AppUsage {
    let name: String            // 应用名
    let bundleID: String        // Bundle ID
    let duration: TimeInterval  // 前台使用秒数
}
```

### NetworkLogEntry

```swift
struct NetworkLogEntry {
    let timestamp: Date
    let downSpeed: Double
    let upSpeed: Double
    let totalRx: UInt64
    let totalTx: UInt64
    let ip: String?
}
```
