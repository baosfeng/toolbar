# 核心接口一览

> ⚠️ **何时阅读：** 当你需要了解本项目公开的核心类、方法签名和参数说明时，请阅读本文档。

## 架构概览

```
NetworkMonitorCore (库目标 — 可测试)
├── Core.swift                  — 工具函数
├── Models.swift                — EventType, TodayStats, AppUsage
├── DatabaseManager.swift       — SQLite 管理器
├── StatsProvider.swift         — 统计查询器
├── ReportGenerator.swift       — 报告生成器
└── SystemSampler.swift         — 系统采样器

NetworkMonitor (可执行目标 — UI)
├── NetworkSpeedMonitor         — 网络速度监控
├── MenuBarManager              — 菜单栏总控制器
├── StatusBarView               — 状态栏视图
├── DetailPanel                 — 浮动详情面板
├── EventMonitor                — 系统事件监听
├── KeyPressMonitor             — 击键计数
└── WindowTitleMonitor          — 窗口标题获取
```

## NetworkSpeedMonitor

网络接口字节计数器读取与速度计算核心类。

**源码位置：** `NetworkMonitor/Sources/NetworkMonitor/NetworkMonitor.swift`

### 属性

| 名称 | 类型 | 访问级别 | 说明 |
|------|------|---------|------|
| `downloadSpeed` | `Double` | `private(set)` | 当前下载速度（字节/秒） |
| `uploadSpeed` | `Double` | `private(set)` | 当前上传速度（字节/秒） |
| `totalRx` | `UInt64` | `private(set)` | 自启动以来总接收字节数 |
| `totalTx` | `UInt64` | `private(set)` | 自启动以来总发送字节数 |

### 方法

| 方法 | 说明 |
|------|------|
| `func poll()` | 采集当前网速，更新 downloadSpeed/uploadSpeed。应周期性调用（如每秒一次） |

## DatabaseManager

SQLite 数据库管理器。

**源码位置：** `NetworkMonitor/Sources/NetworkMonitorCore/DatabaseManager.swift`

### 方法

| 方法 | 说明 |
|------|------|
| `func initialize()` | 打开文件数据库并创建表结构 |
| `func initializeInMemory()` | 打开内存数据库（仅用于测试） |
| `func close()` | 关闭数据库连接 |
| `func flush()` | 刷新事件缓冲区到数据库 |
| `func query(sql:handler:)` | 执行 SELECT 查询，每行回调一次 handler |
| `func writeEvent(type:appName:bundleID:windowTitle:timestamp:)` | 写入系统事件 |
| `func writeKeyPressBatch(count:timestamp:)` | 写入批量击键数据 |
| `func writeSystemSample(timestamp:cpuUsage:memoryUsedMB:memoryTotalMB:networkRx:networkTx:)` | 写入系统采样 |
| `var isReady: Bool` | 数据库是否可用 |
| `var dbPath: String` | 数据库文件路径 |

### 线程安全

- 所有 `sqlite3_*` 调用通过串行队列串行化
- `PRAGMA mmap_size=0` 禁用 mmap（避免 Apple 平台 purgeable 缓存死锁）
- `PRAGMA journal_mode=WAL` 启用 WAL 模式（读写不互斥）

### TodayStats

```swift
struct TodayStats {
    let activeSeconds: TimeInterval     // 活跃时间（秒）
    let keyPressCount: Int              // 击键总数
    let screenOnSeconds: TimeInterval   // 亮屏时间（秒）
    let screenOffSeconds: TimeInterval  // 息屏时间（秒）
    let appRanking: [AppUsage]          // 应用排行
    let cpuUsage: Double                // CPU 使用率
    let memoryUsedMB: Int               // 内存使用（MB）
    let memoryTotalMB: Int              // 总内存（MB）
    let netDownloadSpeed: UInt64        // 网络下载速率
    let netUploadSpeed: UInt64          // 网络上传速率
}
```

### AppUsage

struct AppUsage {

    let bundleID: String        // Bundle ID

## 数据结构

### ProcessNetUsage

```swift
struct ProcessNetUsage {
    let name: String       // 进程名
    let pid: Int32         // 进程 ID
    let bytesIn: UInt64    // 下行速率（字节/秒）
    let bytesOut: UInt64   // 上行速率（字节/秒）
    var total: UInt64 { bytesIn + bytesOut }  // 总速率
}
```

### EventType

```swift
enum EventType: String {
    case appOpen, appClose, appSwitch, windowTitle
    case screenSleep, screenWake
    case systemSleep, systemWake
    case powerAC, powerBattery
    case keyPress
    case systemSample
}
```

### NetworkLogEntry

```swift
struct NetworkLogEntry {
    let timestamp: Date
    let downSpeed: Double
    let upSpeed: Double
    let totalRx: UInt64
    let totalTx: UInt64
    let ip: String?
}
```
