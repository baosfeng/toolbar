# 核心接口一览

> ⚠️ **何时阅读：** 当你需要了解本项目公开的核心类、方法签名和参数说明时，请阅读本文档。

## 架构概览

```
NetworkMonitorCore (库目标 — 领域层 + 基础设施)
├── Domain/Protocols/           — 领域协议 (DatabaseService, TokenStatsService,
│                                  HookEventService, LoggingService, KeyValueStorage,
│                                  NetworkMonitoringService, ProcessNetworkMonitoringService)
├── Infrastructure/             — 实现层 (AppContext, TrafficTracker, Loggers, UserDefaultsStorage)
├── DatabaseManager.swift       — SQLite 管理器（迁移 + 数据保留 + 表达式索引）
├── Core.swift                  — 工具函数（nettop 解析、格式化、sparkline、IP 获取）
├── FormatUtils.swift           — 格式化 + CurrencyConfig + SqliteTimeZone
├── TokenUsageProvider.swift    — Token 用量与 AI 分析查询器
└── ReasonixHookModels.swift    — Hook 事件数据模型与侧车缓存

NetworkMonitor (可执行目标 — UI 层 + 应用层)
├── AppCoordinator.swift        — 服务生命周期协调器（依赖注入）
├── MenuBarManager.swift        — 菜单栏控制器（分层刷新 + NSMenuDelegate）
├── NetworkMonitor.swift        — 网络监控实现（网速 + 进程）
├── StatusBarView.swift         — 状态栏视图
├── TokenChartView.swift        — Token 柱状图（DGCharts）
├── ReasonixHookMonitor.swift   — Hook 事件监听器
├── AppDelegate.swift           — 应用代理
└── main.swift                  — 入口
```

## NetworkSpeedMonitor

网络接口字节计数器读取与速度计算核心类。

**源码位置：** `NetworkMonitor/Sources/NetworkMonitor/NetworkMonitor.swift`

### 属性

| 名称 | 类型 | 访问级别 | 说明 |
|------|------|---------|------|
| `downloadSpeed` | `Double` | `private(set)` | 当前下载速度（字节/秒） |
| `uploadSpeed` | `Double` | `private(set)` | 当前上传速度（字节/秒） |
| `totalRx` | `UInt64` | `private(set)` | 自启动以来总接收字节数 |
| `totalTx` | `UInt64` | `private(set)` | 自启动以来总发送字节数 |

### 方法

| 方法 | 说明 |
|------|------|
| `func poll()` | 采集当前网速，更新 downloadSpeed/uploadSpeed。应周期性调用（如每秒一次） |

## DatabaseManager

SQLite 数据库管理器。

**源码位置：** `NetworkMonitor/Sources/NetworkMonitorCore/DatabaseManager.swift`

### 方法

| 方法 | 说明 |
|------|------|
| `func initialize()` | 打开文件数据库、建表、迁移、启动保留定时器 |
| `func initializeInMemory()` | 打开内存数据库（仅用于测试） |
| `func close()` | 关闭数据库连接 |
| `func query(sql:handler:)` | 执行 SELECT 查询，每行回调一次 handler |
| `func migrateIfNeeded()` | PRAGMA user_version 增量迁移（v1：cost 统一为 CNY） |
| `func purgeExpiredData()` | 清理过期数据（明细 90 天 / 会话 180 天），每日自动执行 |
| `func writeHookEvent(event:)` | 写入 Hook 事件流水 |
| `func upsertHookSession(event:)` | 插入或更新会话汇总（MAX 聚合；状态机：ended/failed/active） |
| `func startHookToolCall(sessionId:turn:toolName:toolArgsJSON:timestamp:)` | 记录工具调用开始 |
| `func finishHookToolCall(sessionId:turn:toolName:status:resultPreview:error:timestamp:)` | 记录工具调用完成 |
| `func queryActiveSessions(limit:)` | 查询活跃会话列表 |
| `func queryToolCalls(sessionId:limit:)` | 查询指定会话的工具调用记录 |
| `var isReady: Bool` | 数据库是否可用 |
| `var dbPath: String` | 数据库文件路径 |

### 表结构

| 表 | 用途 |
|----|------|
| `hook_events` | 事件流水（event_type、session_id、tokens、cost(CNY)、event_data_json、timestamp） |
| `hook_sessions` | 会话汇总（session_id 主键、started_at、累计 tokens/cost、status） |
| `hook_tool_calls` | 工具调用明细（tool_name、status、duration_ms、result_preview、error） |

### 线程安全

- 所有 `sqlite3_*` 调用通过串行队列串行化
- `PRAGMA mmap_size=0` 禁用 mmap（避免 Apple 平台 purgeable 缓存死锁）
- `PRAGMA journal_mode=WAL` 启用 WAL 模式（读写不互斥）

## ReasonixHookMonitor

Reasonix Hook 事件监听器，通过 Unix Domain Socket Datagram 模式接收 Reasonix AI 助手事件。

**源码位置：** `NetworkMonitor/Sources/NetworkMonitor/ReasonixHookMonitor.swift`

| 方法 | 说明 |
|------|------|
| `func start()` | 启动 UDS 监听器，创建 socket 并绑定到 `/tmp/reasonix-hook.sock` |
| `func stop()` | 取消监听（close 由 cancel handler 恰好执行一次） |
| `static func cleanupSocket()` | 删除 socket 文件（应用退出时调用） |

### 线程安全

- `start()` / `stop()` 可在任意线程调用
- `recvfrom` 循环在私有 `DispatchQueue`（`qos: .background`）上运行
- 数据库写入委托给 `DatabaseManager`（内部已串行化）

### 会话侧车缓存

| 属性 | 值 |
|------|-----|
| 最大缓存数 | 100 个会话 |
| TTL | 3600 秒（1 小时） |
| 淘汰策略 | LRU |
| 用途 | 写入 hook_events 时自动补全 model/topic/tokens/cost |

## ReasonixHookModels

Hook 事件数据模型和解析器。

**源码位置：** `NetworkMonitor/Sources/NetworkMonitorCore/ReasonixHookModels.swift`

### ReasonixHookEventType（13 种）

```swift
public enum ReasonixHookEventType: String, Sendable, CaseIterable {
    case sessionStart        // 会话启动
    case sessionEnd          // 会话结束
    case stop                // 轮次完成
    case stopFailure         // 轮次失败
    case userPromptSubmit    // 用户提交消息
    case preToolUse          // 工具调用前
    case postToolUse         // 工具调用后
    case postToolUseFailure  // 工具调用失败
    case permissionRequest   // 权限审批请求
    case notification        // 通知提醒
    case postLLMCall         // 模型推理完成
    case subagentStop        // 子代理完成
    case preCompact          // 上下文压缩前
}
```

### ReasonixHookEvent

```swift
public struct ReasonixHookEvent: Sendable {
    public let eventType: ReasonixHookEventType

    public let cwd: String                  // 工作目录（定位侧车文件）

```

### 方法

| 方法 | 说明 |
|------|------|
| `static func from(jsonData:) throws -> ReasonixHookEvent` | 从 JSON Data 解析；兼容 camelCase/snake_case；抛 `ReasonixHookError` |
| `mutating func enrich(from sidecar:)` | 用侧车数据补全缺失字段（只在字段为空时覆盖） |
| `var isToolStart / isToolEnd / isSessionStart / isSessionEnd / isStop / isStopFailure` | 事件类型判断 |

## 数据结构

### ProcessNetUsage

```swift
struct ProcessNetUsage {
    let name: String       // 进程名
    let pid: Int32         // 进程 ID
    let bytesIn: UInt64    // 下行速率（字节/秒）
    let bytesOut: UInt64   // 上行速率（字节/秒）
    var total: UInt64 { bytesIn + bytesOut }  // 总速率
}
```
