# 核心接口一览

> ⚠️ **何时阅读：** 当你需要了解本项目公开的核心类、方法签名和参数说明时，请阅读本文档。

## 架构概览

```
NetworkMonitorCore (库目标 — 可测试)
├── Core.swift                  — 工具函数
├── Models.swift                — EventType, TodayStats, AppUsage
├── DatabaseManager.swift       — SQLite 管理器
├── StatsProvider.swift         — 统计查询器
├── ReportGenerator.swift       — 报告生成器
├── SystemSampler.swift         — 系统采样器
└── ReasonixHookModels.swift    — Hook 事件数据模型

NetworkMonitor (可执行目标 — UI)
├── NetworkSpeedMonitor         — 网络速度监控
├── MenuBarManager              — 菜单栏总控制器
├── StatusBarView               — 状态栏视图
├── DetailPanel                 — 浮动详情面板
├── EventMonitor                — 系统事件监听
├── KeyPressMonitor             — 击键计数
├── WindowTitleMonitor          — 窗口标题获取
└── ReasonixHookMonitor         — Hook 事件监听器
```

## NetworkSpeedMonitor

网络接口字节计数器读取与速度计算核心类。

**源码位置：** `NetworkMonitor/Sources/NetworkMonitor/NetworkMonitor.swift`

### 属性

| 名称 | 类型 | 访问级别 | 说明 |
|------|------|---------|------|
| `downloadSpeed` | `Double` | `private(set)` | 当前下载速度（字节/秒） |
| `uploadSpeed` | `Double` | `private(set)` | 当前上传速度（字节/秒） |
| `totalRx` | `UInt64` | `private(set)` | 自启动以来总接收字节数 |
| `totalTx` | `UInt64` | `private(set)` | 自启动以来总发送字节数 |

### 方法

| 方法 | 说明 |
|------|------|
| `func poll()` | 采集当前网速，更新 downloadSpeed/uploadSpeed。应周期性调用（如每秒一次） |

## DatabaseManager

SQLite 数据库管理器。

**源码位置：** `NetworkMonitor/Sources/NetworkMonitorCore/DatabaseManager.swift`

### 方法

| 方法 | 说明 |
|------|------|
| `func initialize()` | 打开文件数据库并创建表结构 |
| `func initializeInMemory()` | 打开内存数据库（仅用于测试） |
| `func close()` | 关闭数据库连接 |
| `func flush()` | 刷新事件缓冲区到数据库 |
| `func query(sql:handler:)` | 执行 SELECT 查询，每行回调一次 handler |
| `func writeEvent(type:appName:bundleID:windowTitle:timestamp:)` | 写入系统事件 |
| `func writeKeyPressBatch(count:timestamp:)` | 写入批量击键数据 |
| `func writeSystemSample(timestamp:cpuUsage:memoryUsedMB:memoryTotalMB:networkRx:networkTx:)` | 写入系统采样 |
| `func writeHookEvent(event: ReasonixHookEvent)` | 写入 Reasonix Hook 事件 |
| `func upsertHookSession(event: ReasonixHookEvent)` | 插入或更新 AI 助手会话记录 |
| `func startHookToolCall(sessionId:turn:toolName:toolArgsJSON:timestamp:)` | 记录工具调用开始 |
| `func finishHookToolCall(sessionId:turn:toolName:status:resultPreview:error:timestamp:)` | 记录工具调用完成（成功/失败） |
| `func queryActiveSessions(limit:) -> [[String: Any]]` | 查询活跃会话列表 |
| `func queryToolCalls(sessionId:limit:) -> [[String: Any]]` | 查询指定会话的工具调用记录 |
| `var isReady: Bool` | 数据库是否可用 |
| `var dbPath: String` | 数据库文件路径 |

### 线程安全

- 所有 `sqlite3_*` 调用通过串行队列串行化
- `PRAGMA mmap_size=0` 禁用 mmap（避免 Apple 平台 purgeable 缓存死锁）
- `PRAGMA journal_mode=WAL` 启用 WAL 模式（读写不互斥）

## ReasonixHookMonitor

Reasonix Hook 事件监听器，通过 Unix Domain Socket Datagram 模式接收 Reasonix AI 助手事件。

**源码位置：** `NetworkMonitor/Sources/NetworkMonitor/ReasonixHookMonitor.swift`

### 方法

| 方法 | 说明 |
|------|------|
| `func start()` | 启动 UDS 监听器，创建 socket 并绑定到 `/tmp/reasonix-hook.sock` |
| `func stop()` | 关闭 socket，停止监听 |
| `static func cleanupSocket()` | 删除 socket 文件（应用退出时调用） |

### 线程安全

- `start()` / `stop()` 可在任意线程调用
- `recvfrom` 循环在私有 `DispatchQueue`（`qos: .background`）上运行
- 数据库写入委托给 `DatabaseManager`（内部已串行化）

### 会话侧车缓存

| 属性 | 值 |
|------|-----|
| 最大缓存数 | 100 个会话 |
| TTL | 3600 秒（1 小时） |
| 淘汰策略 | LRU |
| 用途 | 写入 hook_events 时自动补全当前应用、窗口标题、系统摘要 |

### ReasonixHookEventType

```swift
public enum ReasonixHookEventType: String, Sendable, CaseIterable {
    case sessionStart        // 会话启动
    case sessionEnd          // 会话结束
    case stop                // 轮次完成
    case stopFailure         // 轮次失败
    case userPromptSubmit    // 用户提交消息
    case preToolUse          // 工具调用前
    case postToolUse         // 工具调用后
    case postToolUseFailure  // 工具调用失败
    case permissionRequest   // 权限审批请求
    case notification        // 通知提醒
    case postLLMCall         // 模型推理完成
    case subagentStop        // 子代理完成
    case preCompact          // 上下文压缩前
}
```

### SessionSidecarCache

带 TTL 过期和 LRU 淘汰的线程安全缓存，用于缓存会话侧车数据。

**源码位置：** `NetworkMonitor/Sources/NetworkMonitorCore/ReasonixHookModels.swift`

| 方法 | 说明 |
|------|------|
| `func get(_ key:) -> Entry?` | 获取缓存，命中则更新 LRU 顺序；过期返回 nil |
| `func peek(_ key:) -> Entry?` | 窥视缓存但不更新 LRU 顺序 |
| `func touch(_ key:)` | 刷新条目的访问时间 |
| `func set(_ key:data:metaMtime:teleMtime:)` | 写入缓存，超量时淘汰最久未访问条目 |

struct ProcessNetUsage {
