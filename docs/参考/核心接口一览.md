# 核心接口一览

> ⚠️ **何时阅读：** 当你需要了解本项目公开的核心类、方法签名和参数说明时，请阅读本文档。

## NetworkSpeedMonitor

网络接口字节计数器读取与速度计算核心类。

### 属性

| 名称 | 类型 | 访问级别 | 说明 |
|------|------|---------|------|
| `downloadSpeed` | `Double` | `private(set)` | 当前下载速度（字节/秒） |
| `uploadSpeed` | `Double` | `private(set)` | 当前上传速度（字节/秒） |
| `totalRx` | `UInt64` | `private(set)` | 自启动以来总接收字节数 |
| `totalTx` | `UInt64` | `private(set)` | 自启动以来总发送字节数 |

### 方法

| 方法 | 说明 |
|------|------|
| `func poll()` | 采集当前网速，更新 downloadSpeed/uploadSpeed。应周期性调用（如每秒一次） |

## MenuBarManager

菜单栏显示管理类，继承自 `NSObject`。

### 初始化

| 初始化器 | 说明 |
|---------|------|
| `init()` | 创建菜单栏项目并启动定时器 |

### 方法

| 方法 | 说明 |
|------|------|
| `private func setupMenu()` | 设置 NSStatusItem 和下拉菜单 |
| `private func setupTimer()` | 创建 1 秒间隔的 Timer，使用 `.common` mode |
| `@objc private func update()` | Timer 回调，更新菜单栏和下拉菜单的网速显示 |
| `private func formatSpeedShort(_ bps: Double) -> String` | 格式化速度为短字符串（如 "1.2M"、"340K"） |
| `@objc private func quitApp()` | 退出应用 |

## AppDelegate

应用代理类，遵循 `NSApplicationDelegate` 协议。

### 方法

| 方法 | 说明 |
|------|------|
| `func applicationDidFinishLaunching(_ notification: Notification)` | 应用启动完成时初始化 MenuBarManager |
| `func applicationWillTerminate(_ notification: Notification)` | 应用终止时的清理操作 |
