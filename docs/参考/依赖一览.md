# 依赖一览

> ⚠️ **何时阅读：** 当你需要了解项目的外部依赖、运行时要求或兼容性信息时，请阅读本文档。

## 概述

本项目是纯原生 macOS 应用，**含一个第三方图表库**，同时使用 Apple 系统框架和标准库。

## Package 依赖

| 包 | 用途 | 来源 |
|------|------|------|
| DGCharts (Charts) | Token 用量柱状图和历史折线图表 | GitHub (Swift PM) `https://github.com/ChartsOrg/Charts.git` v5.1+ |

## 运行时依赖

| 框架 | 用途 | 来源 |
|------|------|------|
| AppKit | 菜单栏 UI、NSStatusItem、NSMenu、NSApplication | 系统框架（`NetworkMonitor` 目标） |
| Foundation | Date、Timer、ByteCountFormatter、NotificationCenter、UserDefaults | 系统框架（隐式链接） |
| Darwin | getifaddrs、if_data 等系统调用 | 标准库隐式导入 |
| ServiceManagement | 开机自启动管理（SMAppService） | `Package.swift` `linkerSettings` |
| SQLite3 | 本地数据持久化 | 系统库（`SQLite3` 模块） |

## 目标结构

| SwiftPM 目标 | 类型 | 用途 | 依赖 |
|-------------|------|------|------|
| `NetworkMonitorCore` | 库 (`.target`) | 业务逻辑 — 数据库、Token 统计、Hook 模型、工具函数 | 无（仅系统框架） |
| `NetworkMonitor` | 可执行 (`.executableTarget`) | UI — 菜单栏、图表、Hook 监听 | `NetworkMonitorCore` |
| `TestRunner` | 可执行 (`.executableTarget`) | 测试入口 — 工具函数、数据库、Token 统计、Hook 模型 | `NetworkMonitorCore` |

## 数据结构存储

| 存储方式 | 用途 | 位置 |
|---------|------|------|
| SQLite3 | Token 用量、AI 会话与工具调用数据 | `~/Library/Application Support/macMonitor/monitor.db` |

> 说明：统计按本地时区聚合，金额以 CNY 存储；过期数据（明细 90 天 / 会话 180 天）自动清理。
| UserDefaults | 每日流量追踪、开机自启设置、累计流量 | `UserDefaults.standard` |

## 构建依赖

| 工具 | 版本要求 | 用途 |
|------|---------|------|
| Swift 命令行工具 | ≥ 6.3 | 编译、链接 |
| Swift Package Manager | 集成在 Swift 工具链中 | 依赖管理、构建 |

## 平台要求

- **操作系统：** macOS 14 (Sonoma) 或更高版本
- **硬件架构：** ARM64 (Apple Silicon)

## 构建产物

| 产物 | 位置 | 说明 |
|------|------|------|
| 可执行文件 | `.build/debug/NetworkMonitor` | 原始二进制 |
| .app 包 | `dist/NetworkMonitor.app` | 可分发的应用包 |
| 部署包 | `/Applications/NetworkMonitor.app` | 自动部署的正式应用 |

## 测试

测试使用 in-memory SQLite 数据库（`DatabaseManager.initializeInMemory()`），无需真实数据库文件。
运行方式：`swift run --disable-sandbox TestRunner`
