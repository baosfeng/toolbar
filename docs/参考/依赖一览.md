# 依赖一览

> ⚠️ **何时阅读：** 当你需要了解项目的外部依赖、运行时要求或兼容性信息时，请阅读本文档。

## 运行时依赖

本项目是纯原生 macOS 应用，**无第三方依赖**，仅使用 Apple 系统框架。

| 框架 | 用途 | 引用方式 |
|------|------|---------|
| AppKit | 菜单栏 UI、NSStatusItem、NSMenu、NSApplication | 系统框架（`-framework AppKit`） |
| Foundation | Date、Timer、ByteCountFormatter、数值类型 | 系统框架（`-framework Foundation`） |
| Darwin | getifaddrs、if_data 等系统调用接口 | 标准库隐式导入 |

## 构建依赖

| 工具 | 版本要求 | 用途 |
|------|---------|------|
| Swift 命令行工具 | ≥ 6.3 | 编译、链接 |
| Swift Package Manager | 集成在 Swift 工具链中 | 依赖管理、构建 |

## 平台要求

- **操作系统：** macOS 14 (Sonoma) 或更高版本
- **硬件架构：** ARM64 (Apple Silicon)
