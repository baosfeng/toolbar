# 依赖一览

> ⚠️ **何时阅读：** 当你需要了解项目的外部依赖、运行时要求或兼容性信息时，请阅读本文档。

## 概述

本项目是纯原生 macOS 应用，**无第三方依赖**，仅使用 Apple 系统框架和标准库。

## 运行时依赖

| 框架 | 用途 | 来源 |
|------|------|------|
| AppKit | 菜单栏 UI、NSStatusItem、NSMenu、NSApplication、NSPanel | 系统框架（`NetworkMonitor` 目标） |
| Foundation | Date、Timer、ByteCountFormatter、NotificationCenter、UserDefaults | 系统框架（隐式链接） |
| Darwin | getifaddrs、if_data、host_cpu_load_info 等系统调用 | 标准库隐式导入 |
| IOKit.ps | 电池状态读取（IOPSCopyPowerSourcesInfo） | `NetworkMonitorCore` 目标 |
| ServiceManagement | 开机自启动管理（SMAppService） | `Package.swift` `linkerSettings` |
| CoreWLAN | Wi-Fi 信息获取（CWWiFiClient） | `Package.swift` `linkerSettings` |
| SQLite3 | 本地数据持久化 | 系统库（`SQLite3` 模块） |
| ApplicationServices | Accessibility API（AXIsProcessTrusted、AXUIElementCreateApplication） | 系统框架 |

## 目标结构

| SwiftPM 目标 | 类型 | 用途 | 依赖 |
|-------------|------|------|------|
| `NetworkMonitorCore` | 库 (`.target`) | 业务逻辑 — 数据库、统计、报告、采样、工具函数 | 无（仅系统框架） |
| `NetworkMonitor` | 可执行 (`.executableTarget`) | UI — 菜单栏、面板、事件监听 | `NetworkMonitorCore` |
| `TestRunner` | 可执行 (`.executableTarget`) | 测试入口 — 工具函数、数据库、统计报告测试 | `NetworkMonitorCore` |

## 数据结构存储

| 存储方式 | 用途 | 位置 |
|---------|------|------|
| SQLite3 | 系统事件、击键记录、系统采样数据 | `~/Library/Application Support/macMonitor/monitor.db` |
| UserDefaults | 每日流量追踪、开机自启设置、累计流量 | `UserDefaults.standard` |
| 文件系统 | 统计报告（Markdown 格式） | `~/Library/Application Support/macMonitor/reports/` |

## 构建依赖

| 工具 | 版本要求 | 用途 |
|------|---------|------|
| Swift 命令行工具 | ≥ 6.3 | 编译、链接 |
| Swift Package Manager | 集成在 Swift 工具链中 | 依赖管理、构建 |

## 平台要求

- **操作系统：** macOS 14 (Sonoma) 或更高版本
- **硬件架构：** ARM64 (Apple Silicon)

## 构建产物

| 产物 | 位置 | 说明 |
|------|------|------|
| 可执行文件 | `.build/debug/NetworkMonitor` | 原始二进制 |
| .app 包 | `dist/NetworkMonitor.app` | 可分发的应用包 |
| 部署包 | `/Applications/NetworkMonitor.app` | 自动部署的正式应用 |

## 测试

测试使用 in-memory SQLite 数据库（`DatabaseManager.initializeInMemory()`），无需真实数据库文件。
运行方式：`swift run --disable-sandbox TestRunner`
