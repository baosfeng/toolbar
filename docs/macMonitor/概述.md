# macMonitor 本机监控

## 概述

本机监控子系统在后台默默记录你电脑上的活动，所有数据只存在本地。功能覆盖应用追踪、击键统计、屏幕状态和系统资源监控。

## 核心类

| 类名 | 说明 | 源码位置 |
|------|------|---------|
| `EventMonitor` | 系统事件监听器：应用启动/关闭/切换、屏幕睡眠/唤醒、系统睡眠/唤醒 | `NetworkMonitor/Sources/NetworkMonitor/EventMonitor.swift` |
| `KeyPressMonitor` | 击键计数器：使用 NSEvent 全局监听键盘事件，仅计数不记录内容 | `NetworkMonitor/Sources/NetworkMonitor/KeyPressMonitor.swift` |
| `SystemSampler` | 系统采样器：每60秒采集 CPU、内存、网络数据 | `NetworkMonitor/Sources/NetworkMonitorCore/SystemSampler.swift` |
| `WindowTitleMonitor` | 窗口标题获取器：使用 Accessibility API 获取前台窗口标题 | `NetworkMonitor/Sources/NetworkMonitor/WindowTitleMonitor.swift` |
| `DatabaseManager` | SQLite 数据库管理器：数据存储、批量写入、表结构管理 | `NetworkMonitor/Sources/NetworkMonitorCore/DatabaseManager.swift` |
| `StatsProvider` | 统计查询器：从 SQLite 查询今日统计数据 | `NetworkMonitor/Sources/NetworkMonitorCore/StatsProvider.swift` |
| `ReportGenerator` | 报告生成器：生成每日/每周 Markdown 格式统计报告 | `NetworkMonitor/Sources/NetworkMonitorCore/ReportGenerator.swift` |
| `ReasonixHookMonitor` | Reasonix Hook 事件监听器：通过 UDS 接收 AI 助手事件并写入数据库 | `NetworkMonitor/Sources/NetworkMonitor/ReasonixHookMonitor.swift` |
| `TodayStats` | 今日统计数据结构（活跃时间、击键数、CPU/内存、网速等） | `NetworkMonitor/Sources/NetworkMonitorCore/StatsProvider.swift` |
| `AppUsage` | 应用使用数据（应用名、Bundle ID、使用时长） | `NetworkMonitor/Sources/NetworkMonitorCore/StatsProvider.swift` |
| `EventType` | 系统事件类型枚举（app_open、screen_sleep、key_press 等） | `NetworkMonitor/Sources/NetworkMonitorCore/Models.swift` |
| `ReasonixHookEvent` | Hook 事件数据结构，支持 13 种事件类型 | `NetworkMonitor/Sources/NetworkMonitorCore/ReasonixHookModels.swift` |
| `ReasonixHookEventType` | Hook 事件类型枚举（SessionStart、PreToolUse、PostToolUse 等） | `NetworkMonitor/Sources/NetworkMonitorCore/ReasonixHookModels.swift` |
| `SessionSidecarData` | 会话侧车缓存数据（用于 AI 会话自动补全） | `NetworkMonitor/Sources/NetworkMonitorCore/ReasonixHookModels.swift` |

## 事件监听 (EventMonitor)

### 监听的事件

| 事件类型 | 触发条件 | 记录内容 |
|---------|---------|---------|
| `app_open` | 应用启动 | 应用名、Bundle ID、时间 |
| `app_close` | 应用退出 | 应用名、Bundle ID、时间 |
| `app_switch` | 前台应用切换 | 新应用名、旧窗口标题 |
| `window_title` | 窗口标题变化 | 应用名、新标题 |
| `screen_sleep` | 屏幕关闭 | 时间 |
| `screen_wake` | 屏幕亮起 | 时间 |
| `system_sleep` | 系统休眠 | 时间 |
| `system_wake` | 系统唤醒 | 时间 |

### 实现方式

- 使用 `NSWorkspace.shared.notificationCenter` 订阅系统通知
- 纯被动监听，无轮询，几乎不消耗 CPU
- `@MainActor` 确保事件在主线程处理

### 关键代码

```swift
let wnc = NSWorkspace.shared.notificationCenter
wnc.addObserver(self, selector: #selector(appLaunched(_:)), 
                name: NSWorkspace.didLaunchApplicationNotification, object: nil)
wnc.addObserver(self, selector: #selector(screenSleep(_:)), 
                name: NSWorkspace.screensDidSleepNotification, object: nil)
```

## 击键监听 (KeyPressMonitor)

### 设计要点

- 使用 `NSEvent.addGlobalMonitorForEvents(matching: .keyDown)` 全局监听
- **仅累计计数，不记录任何按键内容**
- 每60秒通过 `DispatchSourceTimer` 批量写入数据库
- 需要输入监控权限（`AXIsProcessTrusted()` 检查）
- 启动失败时5秒后自动重试

### 关键代码

```swift
monitor = NSEvent.addGlobalMonitorForEvents(matching: [.keyDown]) { [weak self] _ in
    self?.incrementCount()
}
```

### 数据写入

```swift
// 写入带计数的事件到数据库（timestamp, count）
database.writeKeyPressBatch(count: keyPressCount, timestamp: timestamp)
```

## 系统采样 (SystemSampler)

每60秒进行一次完整采样：

| 采样项 | 实现方式 | 来源 |
|--------|---------|------|
| CPU 使用率 | `host_cpu_load_info()` 读取 CPU ticks | `Darwin/mach` |
| 内存使用 | `host_statistics64()` 读取内存统计 | `Darwin/mach` |
| 网络流量 | `getifaddrs()` 读取接口字节计数器 | `Darwin` |

## 窗口标题 (WindowTitleMonitor)

- 使用 `AXUIElementCreateApplication(pid)` 获取应用 Accessibility 元素
- 通过 `kAXFocusedWindowAttribute` 获取焦点窗口标题
- 仅在应用切换时调用，零持续资源消耗

## 数据存储 (DatabaseManager)

### 数据库位置

```
~/Library/Application Support/macMonitor/monitor.db
```

### 表结构

数据库由 `DatabaseManager` 自动创建，支持以下表（通过 SQLite3 管理）：

| 表名 | 用途 |
|------|------|
| `events` | 系统事件记录（类型、时间戳、应用名、额外数据） |
| `key_press_events` | 击键计数记录（时间戳、计数） |
| `system_samples` | 系统资源采样记录（CPU、内存、网络） |
| `hook_events` | Reasonix Hook 事件记录（事件类型、会话 ID、工具调用、token 用量等） |
| `hook_sessions` | AI 助手会话记录（开始/结束时间、模型、总 token 数） |

### 设计特点

- 事件缓冲区批量写入（每10条或每分钟刷入一次）
- 写入前 / 退出时自动刷新缓冲区
- 使用 `sqlite3_prepare_v2` 预编译语句提高性能

### 关键代码

```swift
class DatabaseManager {
    private var eventBuffer: [String] = []
    private let batchSize = 10
    
    func writeEvent(type: String, timestamp: TimeInterval, appName: String?) {
        eventBuffer.append("...")
        if eventBuffer.count >= batchSize { flush() }
    }
}
```

## 统计查询 (StatsProvider)

### TodayStats 数据结构

```swift
struct TodayStats {
    let activeSeconds: TimeInterval     // 活跃时间（秒）
    let keyPressCount: Int              // 击键总数
    let screenOnSeconds: TimeInterval   // 亮屏时间（秒）
    let screenOffSeconds: TimeInterval  // 息屏时间（秒）
    let appRanking: [AppUsage]          // 应用排行
    let cpuUsage: Double                // CPU 使用率
    let memoryUsedMB: Int               // 内存使用（MB）
    let memoryTotalMB: Int              // 总内存（MB）
    let netDownloadSpeed: UInt64        // 网络下载速率
    let netUploadSpeed: UInt64          // 网络上传速率
}
```

## 报告生成 (ReportGenerator)

- 生成 Markdown 格式统计报告
- 报告保存在 `~/Library/Application Support/macMonitor/reports/`
- 支持每日报告和每周报告
- 文件名格式：`yyyy-MM-dd.md`、`yyyy-WeekWW.md`

## Reasonix Hook 监听

### 概述

`ReasonixHookMonitor` 通过 Unix Domain Socket (UDS) Datagram 模式接收 Reasonix AI 助手（代码辅助代理）运行过程中推送的事件，解析为结构化数据并写入本地 SQLite 数据库。

**源码位置：** `NetworkMonitor/Sources/NetworkMonitor/ReasonixHookMonitor.swift`

### 通信协议

| 属性 | 值 |
|------|-----|
| 协议族 | `AF_UNIX` |
| Socket 类型 | `SOCK_DGRAM` (Datagram) |
| Socket 路径 | `/tmp/reasonix-hook.sock` |
| 数据格式 | UTF-8 JSON |
| 单条上限 | 65,535 字节 |

### 支持的事件类型

| 事件类型 | 中文名 | 是否阻塞 | 是否含 token 信息 |
|---------|--------|---------|-----------------|
| `SessionStart` | 会话启动 | 否 | 否 |
| `SessionEnd` | 会话结束 | 否 | 是 |
| `Stop` | 轮次完成 | 否 | 是 |
| `StopFailure` | 轮次失败 | 否 | 否 |
| `UserPromptSubmit` | 用户提交消息 | **是** | 否 |
| `PreToolUse` | 工具调用前 | **是** | 否 |
| `PostToolUse` | 工具调用后 | 否 | 否 |
| `PostToolUseFailure` | 工具调用失败 | 否 | 否 |
| `PermissionRequest` | 权限审批请求 | 否 | 否 |
| `Notification` | 通知提醒 | 否 | 否 |
| `PostLLMCall` | 模型推理完成 | 否 | 否 |
| `SubagentStop` | 子代理完成 | 否 | 否 |
| `PreCompact` | 上下文压缩前 | 否 | 否 |

### 设计特点

- **后台非阻塞：** 所有 socket 读写和 JSON 解析在私有 `DispatchQueue`（`qos: .background`）上执行，不阻塞主线程
- **会话侧车缓存：** `SessionSidecarCache` 自动缓存 AI 会话信息（TTL 1 小时，最多 100 个会话，LRU 淘汰），写入 hook_events 时自动补全会话上下文（当前应用、窗口标题、系统摘要）
- **健康检查：** `DispatchSourceTimer` 每 5 秒检测 socket 文件是否存在，丢失时自动重建
- **批量写入：** 事件写入委托给 `DatabaseManager`，利用其批量缓冲区减少 IO
- **线程安全：** `start()` / `stop()` 可在任意线程调用，内部通过原子状态管理

### 数据模型

**源码位置：** `NetworkMonitor/Sources/NetworkMonitorCore/ReasonixHookModels.swift`

```swift
public struct ReasonixHookEvent: Sendable {
    public let eventType: ReasonixHookEventType  // 事件类型
    public let sessionId: String                 // 会话 ID
    public let timestamp: Date                   // 事件时间
    public let toolName: String?                 // 工具名（工具调用事件）
    public let toolInput: String?                // 工具输入参数
    public let toolResult: String?               // 工具执行结果
    public let inputTokens: Int?                 // 输入 token 数
    public let outputTokens: Int?                // 输出 token 数
    public let permissionRequired: String?       // 权限请求详情
    public let errorMessage: String?             // 错误信息
    public let notificationBody: String?         // 通知正文
    public let modelName: String?                // 模型名
}
```
